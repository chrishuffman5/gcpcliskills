# gcloud anthos — command index

anthos command Group

- `gcloud anthos create-login-config` — generates a login configuration file
- `gcloud anthos auth login` — authenticate clusters using the Anthos client
- `gcloud anthos config controller create` — create Anthos Config Controller instances
- `gcloud anthos config controller delete` — delete Anthos Config Controller instances
- `gcloud anthos config controller describe` — describe Anthos Config Controller instances
- `gcloud anthos config controller get-config-connector-identity` — fetch default Config Connector identity
- `gcloud anthos config controller get-credentials` — fetch credentials for a running Anthos Config Controller
- `gcloud anthos config controller list` — list Anthos Config Controller instances
- `gcloud anthos config operations describe` — describe Anthos Config Controller operations
- `gcloud anthos config operations list` — list Anthos Config Controller operations
