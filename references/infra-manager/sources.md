# gcloud infra-manager — sources

Official source URLs backing the Infrastructure Manager reference.

- https://cloud.google.com/sdk/gcloud/reference/infra-manager — gcloud CLI reference for all `infra-manager` command groups.
- https://docs.cloud.google.com/infrastructure-manager/docs — product documentation home.
- https://docs.cloud.google.com/infrastructure-manager/docs/overview — product overview, scope, and key concepts.
- https://docs.cloud.google.com/infrastructure-manager/docs/quickstart — quickstart: deploy a VPC using a Git-sourced Terraform module.
- https://docs.cloud.google.com/infrastructure-manager/docs/preview-deployment — create and use previews (terraform plan) before deploying.
- https://docs.cloud.google.com/infrastructure-manager/docs/view-resources — list and describe resources managed under a revision.
- https://docs.cloud.google.com/infrastructure-manager/docs/access-control — IAM roles and permissions for Infrastructure Manager.
