# gcloud infra-manager — command index

manage Infra Manager resources

- `gcloud infra-manager automigrationconfig describe` — describe an AutoMigrationConfig
- `gcloud infra-manager automigrationconfig disable-auto-migration` — disable AutoMigrationConfig
- `gcloud infra-manager automigrationconfig enable-auto-migration` — enable AutoMigrationConfig
- `gcloud infra-manager deployments apply` — create or update a deployment
- `gcloud infra-manager deployments delete` — delete deployments
- `gcloud infra-manager deployments describe` — describe deployments
- `gcloud infra-manager deployments export-lock` — exports lock info of a deployment
- `gcloud infra-manager deployments export-statefile` — export a terraform state file
- `gcloud infra-manager deployments import-statefile` — import a terraform state file
- `gcloud infra-manager deployments list` — list deployments
- `gcloud infra-manager deployments lock` — locks the deployment
- `gcloud infra-manager deployments unlock` — unlocks the deployment
- `gcloud infra-manager previews create` — create a preview
- `gcloud infra-manager previews delete` — delete previews
- `gcloud infra-manager previews describe` — describe previews
- `gcloud infra-manager previews export` — export preview results
- `gcloud infra-manager previews list` — list previews
- `gcloud infra-manager resource-changes describe` — describe resource changes
- `gcloud infra-manager resource-changes list` — list resource changes
- `gcloud infra-manager resource-drifts describe` — describe resource drifts
- `gcloud infra-manager resource-drifts list` — list resource drifts
- `gcloud infra-manager resources describe` — describe resources
- `gcloud infra-manager resources list` — list resources
- `gcloud infra-manager revisions describe` — describe revisions
- `gcloud infra-manager revisions export-statefile` — export a terraform state file
- `gcloud infra-manager revisions list` — list revisions
- `gcloud infra-manager terraform-versions describe` — describe Terraform versions
- `gcloud infra-manager terraform-versions list` — list Terraform versions
