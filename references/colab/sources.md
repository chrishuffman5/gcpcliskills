# Sources — gcloud colab (Colab Enterprise)

Citation record for the `colab` service reference. All URLs verified during research.

## gcloud CLI reference
- https://cloud.google.com/sdk/gcloud/reference/colab — gcloud colab CLI reference (all four command groups and subcommands)
- https://cloud.google.com/sdk/gcloud/reference/beta/colab — gcloud beta colab CLI reference (mirrors GA surface)

## Product documentation
- https://cloud.google.com/colab/docs — Colab Enterprise docs home (product docs home)
- https://cloud.google.com/colab/docs/introduction — Introduction: what Colab Enterprise is and its relationship to Vertex AI
- https://cloud.google.com/colab/docs/quickstart — Console quickstart: enable APIs, create notebook, run code, manage notebooks
- https://cloud.google.com/colab/docs/access-control — IAM roles for Colab Enterprise (admin/user and Vertex AI roles)
- https://cloud.google.com/colab/docs/create-runtime-template — How to create runtime templates (machine type, accelerators, disk, networking, security)
- https://cloud.google.com/colab/docs/manage-runtimes — How to start, stop, disconnect, reconnect, and delete runtimes
