# Sources — gcloud oracle-database (Oracle Database@Google Cloud)

Citation record for the `oracle-database` service reference. All URLs verified during research.
`cloud.google.com/oracle/database/docs/*` URLs redirect (HTTP 301) to
`docs.cloud.google.com/oracle/database/docs/*`; both are official Google domains.

## gcloud CLI reference

- https://cloud.google.com/sdk/gcloud/reference/oracle-database — gcloud CLI reference (63 GA commands across 19 resource groups)
- https://cloud.google.com/sdk/gcloud/reference/oracle-database/autonomous-databases/create — autonomous-databases create reference

## Product documentation

- https://cloud.google.com/oracle/database/docs — product documentation home
- https://cloud.google.com/oracle/database/docs/overview — product overview (architecture, supported services)
- https://cloud.google.com/oracle/database/docs/iam-overview — IAM roles and permission model
- https://cloud.google.com/oracle/database/docs/create-odb-network — create an ODB Network (networking prerequisite)
- https://cloud.google.com/oracle/database/docs/create-exadata-infrastructure — create Exadata Infrastructure
- https://cloud.google.com/oracle/database/docs/create-vm-cluster — create an Exadata VM Cluster
- https://cloud.google.com/oracle/database/docs/create-autonomous-database — create an Autonomous Database
- https://cloud.google.com/oracle/database/docs/reference/rest — REST API reference (confirms `oracledatabase.googleapis.com`)
