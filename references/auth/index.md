# gcloud auth — command index

manage oauth2 credentials for the Google Cloud CLI

- `gcloud auth activate-service-account` — authorize access to Google Cloud with a service account
- `gcloud auth configure-docker` — register gcloud as a Docker credential helper
- `gcloud auth list` — lists credentialed accounts
- `gcloud auth login` — authorize gcloud to access the Cloud Platform with Google user credentials
- `gcloud auth print-access-token` — print an access token for the specified account
- `gcloud auth print-identity-token` — print an identity token for the specified account
- `gcloud auth revoke` — revoke access credentials for an account
- `gcloud auth application-default login` — acquire new user credentials to use for Application Default Credentials
- `gcloud auth application-default print-access-token` — print an access token for your current Application Default Credentials
- `gcloud auth application-default revoke` — revoke previously generated Application Default Credentials
- `gcloud auth application-default set-quota-project` — update or add a quota project in application default credentials (ADC)
- `gcloud auth enterprise-certificate-config create linux` — create an enterprise-certificate configuration file for Linux
- `gcloud auth enterprise-certificate-config create macos` — create an enterprise-certificate configuration file for MacOS
- `gcloud auth enterprise-certificate-config create windows` — create an enterprise-certificate configuration file for Windows
