# gcloud org-policies — command index

create and manage Organization Policies

- `gcloud org-policies delete` — delete an organization policy
- `gcloud org-policies delete-custom-constraint` — deletes a custom constraint
- `gcloud org-policies describe` — describe an organization policy
- `gcloud org-policies describe-custom-constraint` — describe a custom constraint
- `gcloud org-policies list` — list the policies set on a resource
- `gcloud org-policies list-custom-constraints` — lists the custom constraints set on an organization
- `gcloud org-policies reset` — reset the policy to the default for the constraint
- `gcloud org-policies set-custom-constraint` — set a custom constraint from a JSON or YAML file
- `gcloud org-policies set-policy` — set an organization policy from a JSON or YAML file
