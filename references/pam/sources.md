# gcloud pam — sources

Citation record for the `gcloud pam` (Privileged Access Manager) reference. All URLs verified to load (via docs.cloud.google.com).

## gcloud CLI reference

- https://cloud.google.com/sdk/gcloud/reference/pam — gcloud pam GA command reference
- https://cloud.google.com/sdk/gcloud/reference/beta/pam — gcloud beta pam reference (includes the `settings` group)

## Product documentation

- https://cloud.google.com/iam/docs/pam-overview — PAM product overview (product docs home)
- https://cloud.google.com/iam/docs/pam-permissions-and-setup — required IAM roles, service-agent setup, and prerequisites
- https://cloud.google.com/iam/docs/pam-create-entitlements — create entitlements, including sample YAML
- https://cloud.google.com/iam/docs/pam-view-update-delete-entitlements — list, describe, update, export, and delete entitlements
- https://cloud.google.com/iam/docs/pam-request-temporary-elevated-access — requester workflow for creating grants
- https://cloud.google.com/iam/docs/pam-approve-deny-grants — approver workflow (approve, deny, search pending grants)
- https://cloud.google.com/iam/docs/pam-revoke-grants — revoke active grants
