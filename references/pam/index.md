# gcloud pam — command index

manage Privileged Access Manager entitlements and grants

- `gcloud pam check-onboarding-status` — check Privileged Access Manager onboarding status for a resource
- `gcloud pam entitlements create` — create a new Privileged Access Manager entitlement
- `gcloud pam entitlements delete` — delete a Privileged Access Manager entitlement
- `gcloud pam entitlements describe` — show details of a Privileged Access Manager entitlement
- `gcloud pam entitlements export` — export a Privileged Access Manager entitlement into a local YAML file
- `gcloud pam entitlements list` — list all Privileged Access Manager entitlements under a parent
- `gcloud pam entitlements search` — search and list all Privileged Access Manager entitlements in a parent for which you are a requester/approver
- `gcloud pam entitlements update` — update an existing Privileged Access Manager entitlement
- `gcloud pam grants approve` — approve a Privileged Access Manager grant
- `gcloud pam grants create` — create a new Privileged Access Manager grant
- `gcloud pam grants deny` — deny a Privileged Access Manager grant
- `gcloud pam grants describe` — show details of a Privileged Access Manager grant
- `gcloud pam grants list` — list all Privileged Access Manager grants associated with an entitlement
- `gcloud pam grants revoke` — revoke a Privileged Access Manager grant
- `gcloud pam grants search` — search for and list all Privileged Access Manager grants you have created, have approved, or can approve
- `gcloud pam operations delete` — delete a Privileged Access Manager long running operation
- `gcloud pam operations describe` — show details of a Privileged Access Manager long running operation
- `gcloud pam operations list` — list all Privileged Access Manager long running operations under a location
- `gcloud pam operations wait` — poll a Privileged Access Manager long running operation
