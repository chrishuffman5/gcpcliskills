# gcloud parametermanager — command index

parameter Manager is a single source of truth to store, access and manage the lifecycle of your application parameters

- `gcloud parametermanager parameters create` — creates a Parameter Manager parameter
- `gcloud parametermanager parameters delete` — deletes a single Parameter Manager parameter resource
- `gcloud parametermanager parameters describe` — gets a single Parameter Manager parameter
- `gcloud parametermanager parameters list` — lists Parameter Manager parameters
- `gcloud parametermanager parameters update` — updates the metadata of an Parameter Manager parameter resource
- `gcloud parametermanager parameters versions create` — creates an Parameter Manager parameter version
- `gcloud parametermanager parameters versions delete` — deletes a single Parameter Manager parameter version
- `gcloud parametermanager parameters versions describe` — gets a single Parameter Manager parameter version
- `gcloud parametermanager parameters versions list` — list Parameter Manager parameter versions
- `gcloud parametermanager parameters versions render` — gets a single Parameter Manager parameter version render
- `gcloud parametermanager parameters versions update` — updates the properties of a single Parameter Manager parameter version
