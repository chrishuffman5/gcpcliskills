# gcloud essential-contacts — command index

manage Essential Contacts

- `gcloud essential-contacts compute` — compute the essential contacts that are subscribed to the specified notification categories for a resource
- `gcloud essential-contacts create` — create an essential contact
- `gcloud essential-contacts delete` — delete an essential contact
- `gcloud essential-contacts describe` — describe an essential contact
- `gcloud essential-contacts list` — list essential contacts for a resource
- `gcloud essential-contacts update` — update an essential contact
