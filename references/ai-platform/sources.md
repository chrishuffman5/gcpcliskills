# gcloud ai-platform — sources

Official source URLs underpinning this reference. AI Platform is a legacy service
that has been largely superseded by Vertex AI (`gcloud ai`); several product-doc
URLs now redirect to the Vertex AI documentation.

## gcloud CLI reference

- https://cloud.google.com/sdk/gcloud/reference/ai-platform — GA command/flag reference
- https://cloud.google.com/sdk/gcloud/reference/beta/ai-platform — beta reference (adds `explain`)
- https://cloud.google.com/sdk/gcloud/reference/alpha/ai-platform — alpha reference (adds `explain`, `locations`)

## Product documentation

- https://cloud.google.com/ai-platform/docs — AI Platform docs home (product landing page; redirects to Vertex AI)
- https://cloud.google.com/vertex-ai/docs/start/migrating-to-vertex-ai — migration guide to Vertex AI
- https://cloud.google.com/ai-platform/training/docs/overview — AI Platform Training overview
- https://cloud.google.com/ai-platform/prediction/docs/overview — AI Platform Prediction overview
- https://cloud.google.com/ai-platform/prediction/docs/deploying-models — deploying a model version
- https://cloud.google.com/ai-platform/prediction/docs/managing-models-jobs — managing models and versions
- https://cloud.google.com/ai-platform/prediction/docs/runtime-version-list — supported runtime / Python versions
- https://cloud.google.com/ai-platform/prediction/docs/regional-endpoints — global + regional endpoints
- https://cloud.google.com/iam/docs/roles-permissions/ml — predefined AI Platform IAM roles (`roles/ml.*`)
