# gcloud ai-platform — command index

manage AI Platform jobs and models

- `gcloud ai-platform predict` — run AI Platform online prediction
- `gcloud ai-platform jobs cancel` — cancel a running AI Platform job
- `gcloud ai-platform jobs describe` — describe an AI Platform job
- `gcloud ai-platform jobs list` — list existing AI Platform jobs
- `gcloud ai-platform jobs stream-logs` — show logs from a running AI Platform job
- `gcloud ai-platform jobs update` — update an AI Platform job
- `gcloud ai-platform jobs submit prediction` — start an AI Platform batch prediction job
- `gcloud ai-platform jobs submit training` — submit an AI Platform training job
- `gcloud ai-platform local predict` — run prediction locally
- `gcloud ai-platform local train` — run an AI Platform training job locally
- `gcloud ai-platform models add-iam-policy-binding` — add IAM policy binding for a model
- `gcloud ai-platform models create` — create a new AI Platform model
- `gcloud ai-platform models delete` — delete an existing AI Platform model
- `gcloud ai-platform models describe` — describe an existing AI Platform model
- `gcloud ai-platform models get-iam-policy` — get the IAM policy for a model
- `gcloud ai-platform models list` — list existing AI Platform models
- `gcloud ai-platform models remove-iam-policy-binding` — remove IAM policy binding for a model
- `gcloud ai-platform models set-iam-policy` — set the IAM policy for a model
- `gcloud ai-platform models update` — update an existing AI Platform model
- `gcloud ai-platform operations cancel` — cancel an AI Platform operation
- `gcloud ai-platform operations describe` — describe an AI Platform operation
- `gcloud ai-platform operations list` — list existing AI Platform jobs
- `gcloud ai-platform operations wait` — wait for an AI Platform operation to complete
- `gcloud ai-platform versions create` — create a new AI Platform version
- `gcloud ai-platform versions delete` — delete an existing AI Platform version
- `gcloud ai-platform versions describe` — describe an existing AI Platform version
- `gcloud ai-platform versions list` — list existing AI Platform versions
- `gcloud ai-platform versions set-default` — sets an existing AI Platform version as the default for its model
- `gcloud ai-platform versions update` — update an AI Platform version
