# gcloud privateca — sources

Official sources for the `gcloud privateca` (Certificate Authority Service) reference.

- https://cloud.google.com/sdk/gcloud/reference/privateca — gcloud CLI reference for all privateca command groups.
- https://cloud.google.com/certificate-authority-service/docs — Certificate Authority Service product documentation home (overview, concepts, how-to guides).
- https://cloud.google.com/certificate-authority-service/docs/quickstart — Quickstart: create a CA pool and root CA, request a certificate, and clean up.
- https://cloud.google.com/certificate-authority-service/docs/creating-ca-pool — How to create a CA pool via Console, gcloud, Terraform, or REST.
- https://cloud.google.com/certificate-authority-service/docs/creating-certificate-authorities — How to create a root CA (STAGED by default, then enable it).
- https://cloud.google.com/certificate-authority-service/docs/creating-certificate-template — How to create certificate templates with X.509 constraints and CEL identity expressions.
- https://cloud.google.com/certificate-authority-service/docs/access-control — IAM roles for CA Service and their permissions.
- https://cloud.google.com/certificate-authority-service/docs/reference/rest — REST API reference for privateca.googleapis.com.
