# gcloud privateca locations

manage locations

### `gcloud privateca locations list`

List supported locations for the Private CA GA API

Returns supported locations where resources can be managed through the
Private CA GA API.

**Synopsis:**
```
gcloud privateca locations list [--filter=EXPRESSION] [--limit=LIMIT]
    [--page-size=PAGE_SIZE] [--sort-by=[FIELD,...]] [--uri]
    [GCLOUD_WIDE_FLAG ...]
```

**Examples:**
```bash
To list the locations available for the Private CA GA API:

    $ gcloud privateca locations list
```

[Official reference](https://cloud.google.com/sdk/gcloud/reference/privateca/locations/list)
