# gcloud network-management — command index

manage Network Management resources

- `gcloud network-management connectivity-tests create` — create a new connectivity test
- `gcloud network-management connectivity-tests delete` — delete a connectivity test
- `gcloud network-management connectivity-tests describe` — describe a connectivity test
- `gcloud network-management connectivity-tests list` — list connectivity tests
- `gcloud network-management connectivity-tests rerun` — rerun a connectivity test
- `gcloud network-management connectivity-tests update` — update an existing connectivity test
- `gcloud network-management operations describe` — describe a Network Management operation
- `gcloud network-management operations list` — list Network Management operations
- `gcloud network-management vpc-flow-logs-configs create` — creates a new VPC Flow Logs configuration
- `gcloud network-management vpc-flow-logs-configs delete` — deletes the specified VPC Flow Logs configuration
- `gcloud network-management vpc-flow-logs-configs describe` — describe the details of a specific VPC Flow Logs configuration
- `gcloud network-management vpc-flow-logs-configs list` — list all VPC Flow Logs configurations
- `gcloud network-management vpc-flow-logs-configs query-org-vpc-flow-logs-configs` — fetch all organization-level VPC Flow Logs configurations associated with the project
- `gcloud network-management vpc-flow-logs-configs show-effective-flow-logs-configs` — show all effective VPC Flow Logs configurations for a resource
- `gcloud network-management vpc-flow-logs-configs update` — updates one or more fields in an existing VPC Flow Logs configuration
