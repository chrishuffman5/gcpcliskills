# gcloud app — sources

Official source URLs for the `gcloud app` (App Engine) reference.

- https://cloud.google.com/sdk/gcloud/reference/app — gcloud CLI reference for `gcloud app` (all 49 GA commands)
- https://cloud.google.com/sdk/gcloud/reference/beta/app — gcloud `beta app` reference (beta surface, including `migrate-to-run`)
- https://cloud.google.com/appengine/docs — App Engine product documentation home
- https://cloud.google.com/appengine/docs/standard/python3/quickstart — Python 3 quickstart on the Standard environment
- https://cloud.google.com/appengine/docs/standard/configuration-files — Standard environment configuration files (`app.yaml`, `cron.yaml`, `dispatch.yaml`, `index.yaml`)
- https://cloud.google.com/appengine/docs/standard/splitting-traffic — Traffic splitting how-to (IP, cookie, random)
- https://cloud.google.com/appengine/docs/standard/roles — IAM roles for App Engine
