# gcloud bq — sources

Official source URLs for the `gcloud bq` (BigQuery Migration Service) reference. All verified
to load (docs.cloud.google.com mirror, 2026-05-27).

> Note: the full-featured BigQuery CLI is the separate standalone `bq` command, not `gcloud bq`.
> The GA `gcloud bq` surface covers only migration workflows.

## gcloud CLI reference

- https://cloud.google.com/sdk/gcloud/reference/bq — gcloud bq (GA: migration-workflows only)
- https://cloud.google.com/sdk/gcloud/reference/bq/migration-workflows — migration-workflows subgroup
- https://cloud.google.com/sdk/gcloud/reference/beta/bq — gcloud beta bq
- https://cloud.google.com/sdk/gcloud/reference/alpha/bq — gcloud alpha bq (full surface)
- https://cloud.google.com/sdk/gcloud/reference/alpha/bq/datasets — alpha datasets subgroup
- https://cloud.google.com/sdk/gcloud/reference/alpha/bq/tables — alpha tables subgroup
- https://cloud.google.com/sdk/gcloud/reference/alpha/bq/translation — alpha translation subgroup
