# gcloud publicca — sources

Official source URLs for the `gcloud publicca` (Public Certificate Authority) reference. All were fetched and confirmed to load relevant official content during research.

## gcloud CLI reference

- https://cloud.google.com/sdk/gcloud/reference/publicca — `gcloud publicca` command group reference root.
- https://cloud.google.com/sdk/gcloud/reference/publicca/external-account-keys/create — CLI reference for the single GA command (flags, synopsis, examples).
- https://cloud.google.com/sdk/gcloud/reference/beta/publicca — `gcloud beta publicca` reference.
- https://cloud.google.com/sdk/gcloud/reference/alpha/publicca — `gcloud alpha publicca` reference.

## Product documentation

- https://cloud.google.com/certificate-manager/docs/public-ca — Public CA product docs home; overview and supported ACME challenge types.
- https://cloud.google.com/certificate-manager/docs/public-ca-tutorial — tutorial: request a certificate using Public CA and Certbot (EAB → ACME → certificate flow).
- https://cloud.google.com/certificate-manager/docs/overview — Certificate Manager overview; context for where Public CA sits.
- https://cloud.google.com/certificate-manager/docs/domain-authorization — domain authorization types (DNS vs. load-balancer methods).
- https://cloud.google.com/certificate-manager/docs/permissions — IAM roles reference for Certificate Manager and Public CA.
