# gcloud workbench — command index

workbench Command Group

- `gcloud workbench instances add-iam-policy-binding` — adds IAM policy binding for a workbench instance
- `gcloud workbench instances check-instance-upgradability` — checks if a workbench instance is upgradeable
- `gcloud workbench instances create` — creates a workbench instance
- `gcloud workbench instances delete` — deletes a workbench instance
- `gcloud workbench instances describe` — describes a workbench instance
- `gcloud workbench instances diagnose` — diagnoses a workbench instance
- `gcloud workbench instances get-config` — describes the valid configurations for workbench instances
- `gcloud workbench instances get-iam-policy` — gets IAM policy for a workbench instance
- `gcloud workbench instances list` — lists workbench instances
- `gcloud workbench instances remove-iam-policy-binding` — removes IAM policy binding for a workbench instance
- `gcloud workbench instances reset` — resets a workbench instance
- `gcloud workbench instances resize-disk` — resizes the workbench instance's disk
- `gcloud workbench instances restore` — restores the workbench instance to a snapshot state
- `gcloud workbench instances rollback` — rolls back a workbench instance
- `gcloud workbench instances set-iam-policy` — sets the IAM policy for a workbench instance
- `gcloud workbench instances start` — starts a workbench instance
- `gcloud workbench instances stop` — stops a workbench instance
- `gcloud workbench instances update` — updates a workbench instance
- `gcloud workbench instances upgrade` — upgrades a workbench instance
