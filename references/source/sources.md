# Sources — gcloud source (Cloud Source Repositories)

Citation record for the `gcloud source` service reference. CSR is deprecated to
new customers as of June 17, 2024; see the docs home for details.

## gcloud CLI reference
- https://cloud.google.com/sdk/gcloud/reference/source — `gcloud source` command group reference (subgroups: `project-configs`, `repos`).
- https://cloud.google.com/sdk/gcloud/reference/beta/source — beta reference; same subgroup surface as GA.
- https://cloud.google.com/sdk/gcloud/reference/alpha/source — alpha reference; adds `repos config export`.

## Product documentation
- https://cloud.google.com/source-repositories/docs — Cloud Source Repositories documentation home (product docs home; confirms June 17, 2024 deprecation to new customers).
- https://cloud.google.com/source-repositories/docs/quickstart — Quickstart: enable the API, create a repo, push code.
- https://cloud.google.com/source-repositories/docs/create-code-repository — Create a new empty repository via console or gcloud CLI.
- https://cloud.google.com/source-repositories/docs/authentication — Set up local auth (SSH keys, gcloud credential helper, generated credentials).
- https://cloud.google.com/source-repositories/docs/reference/rest — Cloud Source Repositories REST API reference.

## IAM
- https://cloud.google.com/iam/docs/roles-permissions/source — predefined IAM roles for Cloud Source Repositories (`roles/source.*`).
