# gcloud source — command index

cloud git repository commands

- `gcloud source project-configs describe` — show details about the configuration of a project
- `gcloud source project-configs update` — update the Cloud Source Repositories configuration of the current project
- `gcloud source repos clone` — clone a cloud source repository
- `gcloud source repos create` — create a cloud source repository
- `gcloud source repos delete` — delete a cloud source repository
- `gcloud source repos describe` — describe a cloud source repository
- `gcloud source repos get-iam-policy` — get the IAM policy for the named cloud source repository
- `gcloud source repos list` — list the repositories the currently active project
- `gcloud source repos set-iam-policy` — set the IAM policy for the named repository
- `gcloud source repos update` — update the configuration of a Cloud Source Repository
