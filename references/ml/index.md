# gcloud ml — command index

use Google Cloud machine learning capabilities

- `gcloud ml language analyze-entities` — use Google Cloud Natural Language API to identify entities in text
- `gcloud ml language analyze-entity-sentiment` — use Google Cloud Natural Language API to identify entity-level sentiment
- `gcloud ml language analyze-sentiment` — use Google Cloud Natural Language API to identify sentiments in a text
- `gcloud ml language analyze-syntax` — use Google Cloud Natural Language API to identify linguistic information
- `gcloud ml language classify-text` — classifies input document into categories
- `gcloud ml speech recognize` — get transcripts of short (less than 60 seconds) audio from an audio file
- `gcloud ml speech recognize-long-running` — get transcripts of longer audio from an audio file
- `gcloud ml speech operations describe` — get description of a long-running speech recognition operation
- `gcloud ml speech operations wait` — poll long-running speech recognition operation until it completes
- `gcloud ml video detect-explicit-content` — detect explicit content in videos
- `gcloud ml video detect-labels` — detect general labels for videos
- `gcloud ml video detect-shot-changes` — detect shot changes in videos
- `gcloud ml video operations describe` — get description of a long-running video analysis operation
- `gcloud ml video operations wait` — poll long-running video analysis operation until it completes
- `gcloud ml vision detect-document` — detect dense text in an image
- `gcloud ml vision detect-faces` — detect faces within an image
- `gcloud ml vision detect-image-properties` — detect general attributes of an image
- `gcloud ml vision detect-labels` — detect broad sets of categories within an image
- `gcloud ml vision detect-landmarks` — detect popular natural and man-made structures within an image
- `gcloud ml vision detect-logos` — detect popular product logos within an image
- `gcloud ml vision detect-objects` — detect and extract multiple objects in an image with object localization
- `gcloud ml vision detect-safe-search` — detect explicit content in an image
- `gcloud ml vision detect-text` — detect and extract text within an image
- `gcloud ml vision detect-text-pdf` — detect and transcribe text from PDF files stored in Google Cloud Storage
- `gcloud ml vision detect-text-tiff` — detect and transcribe text from TIFF files stored in Google Cloud Storage
- `gcloud ml vision detect-web` — detect entities in an image from similar images on the web
- `gcloud ml vision suggest-crop` — suggest a bounding box in an image
