# gcloud beyondcorp — command index

manage Beyondcorp resources

- `gcloud beyondcorp operations describe` — describe operations
- `gcloud beyondcorp operations list` — list operations
- `gcloud beyondcorp security-gateways create` — create securityGateways
- `gcloud beyondcorp security-gateways delete` — delete securityGateways
- `gcloud beyondcorp security-gateways describe` — describe securityGateways
- `gcloud beyondcorp security-gateways get-iam-policy` — get the IAM policy for a security gateway
- `gcloud beyondcorp security-gateways list` — list securityGateways
- `gcloud beyondcorp security-gateways set-iam-policy` — set the IAM policy for a security gateway
- `gcloud beyondcorp security-gateways update` — update securityGateways
- `gcloud beyondcorp security-gateways applications create` — create applications
- `gcloud beyondcorp security-gateways applications delete` — delete applications
- `gcloud beyondcorp security-gateways applications describe` — describe applications
- `gcloud beyondcorp security-gateways applications get-iam-policy` — get the IAM policy for a security gateway application
- `gcloud beyondcorp security-gateways applications list` — list applications
- `gcloud beyondcorp security-gateways applications set-iam-policy` — set the IAM policy for a security gateway application
- `gcloud beyondcorp security-gateways applications update` — update applications
