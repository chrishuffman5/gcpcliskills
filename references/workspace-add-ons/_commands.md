# gcloud workspace-add-ons (top-level commands)

### `gcloud workspace-add-ons get-authorization`

Gets the authorization information for deployments in a given project

**Synopsis:**
```
gcloud workspace-add-ons get-authorization [GCLOUD_WIDE_FLAG ...]
```

**Examples:**
```bash
To get authorization information for deployments in a given project

    $ gcloud workspace-add-ons get-authorization
```

[Official reference](https://cloud.google.com/sdk/gcloud/reference/workspace-add-ons/get-authorization)
