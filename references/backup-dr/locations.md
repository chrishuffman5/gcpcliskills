# gcloud backup-dr locations

manage Backup and DR locations

### `gcloud backup-dr locations list`

List available Backup and DR locations

List all locations where Backup and DR Service is available.

**Synopsis:**
```
gcloud backup-dr locations list [--filter=EXPRESSION] [--limit=LIMIT]
    [--page-size=PAGE_SIZE] [--sort-by=[FIELD,...]] [--uri]
    [GCLOUD_WIDE_FLAG ...]
```

**Examples:**
```bash
To list all locations, run:

    $ gcloud backup-dr locations list
```

[Official reference](https://cloud.google.com/sdk/gcloud/reference/backup-dr/locations/list)
