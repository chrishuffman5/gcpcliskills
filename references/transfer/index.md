# gcloud transfer — command index

manage Transfer Service jobs, operations, and agents

- `gcloud transfer authorize` — authorize an account for all Transfer Service features
- `gcloud transfer agent-pools create` — create a Transfer Service agent pool
- `gcloud transfer agent-pools delete` — delete a Transfer Service agent pool
- `gcloud transfer agent-pools describe` — get details about a specific agent pool
- `gcloud transfer agent-pools list` — list Transfer Service transfer agent pools
- `gcloud transfer agent-pools update` — update a Transfer Service agent pool
- `gcloud transfer agents delete` — delete Transfer Service transfer agents
- `gcloud transfer agents install` — install Transfer Service agents
- `gcloud transfer jobs create` — create a Transfer Service transfer job
- `gcloud transfer jobs delete` — delete a Transfer Service transfer job
- `gcloud transfer jobs describe` — get configuration and latest operation details about transfer job
- `gcloud transfer jobs list` — list Transfer Service transfer jobs
- `gcloud transfer jobs monitor` — track progress in real time for a transfer job's latest operation
- `gcloud transfer jobs run` — run a Transfer Service transfer job
- `gcloud transfer jobs update` — update a Transfer Service transfer job
- `gcloud transfer operations cancel` — cancel a transfer operation
- `gcloud transfer operations describe` — get configuration and latest transfer operation details
- `gcloud transfer operations list` — list Transfer Service transfer operations
- `gcloud transfer operations monitor` — track progress in real time for a transfer operation
- `gcloud transfer operations pause` — pause a currently running transfer operation
- `gcloud transfer operations resume` — resume a currently paused transfer operation
