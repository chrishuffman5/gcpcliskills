# gcloud functions — command index

manage Google Cloud Functions

- `gcloud functions add-iam-policy-binding` — adds an IAM policy binding for a Google Cloud Function
- `gcloud functions add-invoker-policy-binding` — adds an invoker binding to the IAM policy of a Google Cloud Function
- `gcloud functions call` — triggers execution of a Google Cloud Function
- `gcloud functions delete` — delete a Google Cloud Function
- `gcloud functions deploy` — create or update a Google Cloud Function
- `gcloud functions describe` — display details of a Google Cloud Function
- `gcloud functions detach` — detach a Cloud Functions v2 function from its existing environment and make it a native Cloud Run function
- `gcloud functions get-iam-policy` — get IAM policy for a Google Cloud Function
- `gcloud functions list` — list Google Cloud Functions
- `gcloud functions remove-iam-policy-binding` — removes an IAM policy binding from a Google Cloud Function
- `gcloud functions remove-invoker-policy-binding` — removes an invoker binding from the IAM policy of a Google Cloud Function
- `gcloud functions set-iam-policy` — sets IAM policy for a Google Cloud Function
- `gcloud functions event-types list` — list types of events that can be a trigger for a Google Cloud Function
- `gcloud functions logs read` — display log entries produced by Google Cloud Functions
- `gcloud functions regions list` — list regions available to Google Cloud Functions
- `gcloud functions runtimes list` — list runtimes available to Google Cloud Functions
