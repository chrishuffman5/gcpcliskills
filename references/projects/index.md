# gcloud projects — command index

create and manage project access policies

- `gcloud projects add-iam-policy-binding` — add IAM policy binding for a project
- `gcloud projects create` — create a new project
- `gcloud projects delete` — delete a project
- `gcloud projects describe` — show metadata for a project
- `gcloud projects get-ancestors` — get the ancestors for a project
- `gcloud projects get-ancestors-iam-policy` — get IAM policies for a project and its ancestors
- `gcloud projects get-iam-policy` — get IAM policy for a project
- `gcloud projects list` — list projects accessible by the active account
- `gcloud projects remove-iam-policy-binding` — remove IAM policy binding for a project
- `gcloud projects set-iam-policy` — set IAM policy for a project
- `gcloud projects undelete` — undelete a project
- `gcloud projects update` — update the name of a project
