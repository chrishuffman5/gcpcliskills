# gcloud access-approval — command index

manage Access Approval requests and settings

- `gcloud access-approval requests approve` — approve an Access Approval request
- `gcloud access-approval requests dismiss` — dismiss an Access Approval request
- `gcloud access-approval requests get` — get an Access Approval request
- `gcloud access-approval requests invalidate` — invalidate an Access Approval request
- `gcloud access-approval requests list` — list Access Approval requests
- `gcloud access-approval service-account get` — get Access Approval service account
- `gcloud access-approval settings delete` — delete Access Approval settings
- `gcloud access-approval settings get` — get Access Approval settings
- `gcloud access-approval settings update` — update Access Approval settings
