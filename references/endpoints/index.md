# gcloud endpoints — command index

create, enable and manage API services

- `gcloud endpoints configs describe` — describes the configuration for a given version of a service
- `gcloud endpoints configs list` — lists the configurations for a given service
- `gcloud endpoints operations describe` — describes an operation resource for a given operation name
- `gcloud endpoints operations list` — list operations for a project
- `gcloud endpoints operations wait` — waits for an operation to complete
- `gcloud endpoints services add-iam-policy-binding` — add IAM policy binding to a service
- `gcloud endpoints services check-iam-policy` — returns information about a principal's permissions on a service
- `gcloud endpoints services delete` — deletes a service from Google Service Management
- `gcloud endpoints services deploy` — deploys a service configuration for the given service name
- `gcloud endpoints services describe` — describes a service given a service name
- `gcloud endpoints services get-iam-policy` — describes the IAM policy for a service
- `gcloud endpoints services list` — list services for a project
- `gcloud endpoints services remove-iam-policy-binding` — remove IAM policy binding from a service
- `gcloud endpoints services undelete` — undeletes a service configuration that was previously deleted
