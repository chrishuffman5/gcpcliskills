# gcloud secrets — command index

manage secrets on Google Cloud

- `gcloud secrets add-iam-policy-binding` — add IAM policy binding to a secret
- `gcloud secrets create` — create a new secret
- `gcloud secrets delete` — delete a secret
- `gcloud secrets describe` — describe a secret's metadata
- `gcloud secrets get-iam-policy` — get the IAM policy for the secret
- `gcloud secrets list` — list all secret names
- `gcloud secrets remove-iam-policy-binding` — remove IAM policy binding for a secret
- `gcloud secrets set-iam-policy` — set the IAM policy binding for a secret
- `gcloud secrets update` — update a secret's metadata
- `gcloud secrets locations describe` — describe a location
- `gcloud secrets locations list` — list all available locations
- `gcloud secrets replication get` — describe a secret's replication
- `gcloud secrets replication set` — set a secret's replication
- `gcloud secrets replication update` — update a secret replica's metadata
- `gcloud secrets versions access` — access a secret version's data
- `gcloud secrets versions add` — create a new version of an existing secret
- `gcloud secrets versions describe` — describe metadata about the secret version
- `gcloud secrets versions destroy` — destroy a secret version's metadata and secret data
- `gcloud secrets versions disable` — disable the version of the provided secret
- `gcloud secrets versions enable` — enable the version of the provided secret
- `gcloud secrets versions list` — list all versions for a secret
