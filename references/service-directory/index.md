# gcloud service-directory — command index

command groups for Service Directory

- `gcloud service-directory endpoints create` — creates an endpoint
- `gcloud service-directory endpoints delete` — deletes an endpoint
- `gcloud service-directory endpoints describe` — describes an endpoint
- `gcloud service-directory endpoints list` — lists endpoints
- `gcloud service-directory endpoints update` — updates an endpoint
- `gcloud service-directory locations describe` — describes a location
- `gcloud service-directory locations list` — lists locations
- `gcloud service-directory namespaces add-iam-policy-binding` — adds IAM policy binding to a namespace
- `gcloud service-directory namespaces create` — creates a namespace
- `gcloud service-directory namespaces delete` — deletes a namespace
- `gcloud service-directory namespaces describe` — describes a namespace
- `gcloud service-directory namespaces get-iam-policy` — gets IAM policy for a namespace
- `gcloud service-directory namespaces list` — lists namespaces
- `gcloud service-directory namespaces remove-iam-policy-binding` — removes IAM policy binding from a namespace
- `gcloud service-directory namespaces set-iam-policy` — sets IAM policy for a namespace
- `gcloud service-directory namespaces update` — updates a namespace
- `gcloud service-directory services add-iam-policy-binding` — adds IAM policy binding to a service
- `gcloud service-directory services create` — creates a service
- `gcloud service-directory services delete` — deletes a service
- `gcloud service-directory services describe` — describes a service
- `gcloud service-directory services get-iam-policy` — gets IAM policy for a service
- `gcloud service-directory services list` — lists services
- `gcloud service-directory services remove-iam-policy-binding` — removes IAM policy binding from a service
- `gcloud service-directory services resolve` — resolves a service
- `gcloud service-directory services set-iam-policy` — sets IAM policy for a service
- `gcloud service-directory services update` — updates a service
