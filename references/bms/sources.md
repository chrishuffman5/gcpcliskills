# gcloud bms — sources

Official sources for the Bare Metal Solution service reference. All URLs
verified against the research brief (cloud.google.com URLs redirect to the
equivalent docs.cloud.google.com page).

## gcloud CLI reference

- https://cloud.google.com/sdk/gcloud/reference/bms — GA command/flag reference
- https://cloud.google.com/sdk/gcloud/reference/alpha/bms — alpha command/flag reference

## Product documentation

- https://cloud.google.com/bare-metal/docs — product documentation home
- https://cloud.google.com/bare-metal/docs/bms-planning — planning guide (regions, server configs, OS images, storage types, networking)
- https://cloud.google.com/bare-metal/docs/bms-iam — IAM & access control (predefined roles)
