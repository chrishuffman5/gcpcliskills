# Sources — gcloud topic (CLI supplementary help guides)

Official source URLs backing this reference. `gcloud topic` is part of the gcloud CLI
itself (no separate product), so the canonical home is the gcloud SDK documentation.
All URLs were WebFetch-verified during research on 2026-05-27.

## gcloud CLI reference
- https://cloud.google.com/sdk/gcloud/reference/topic — `gcloud topic` index of all 18 supplementary help guides (product docs home)
- https://cloud.google.com/sdk/gcloud/reference/topic/filters — `--filter` expression syntax and operators
- https://cloud.google.com/sdk/gcloud/reference/topic/formats — all `--format` values and `NAME[ATTRIBUTES](PROJECTION)` syntax
- https://cloud.google.com/sdk/gcloud/reference/topic/projections — projection keys, transform functions, column attributes
- https://cloud.google.com/sdk/gcloud/reference/topic/datetimes — absolute and relative date/time input formats
- https://cloud.google.com/sdk/gcloud/reference/topic/escaping — `^DELIM^` alternate-delimiter syntax for list/dict flags
- https://cloud.google.com/sdk/gcloud/reference/topic/configurations — named configuration lifecycle and usage
- https://cloud.google.com/sdk/gcloud/reference/topic/gcloudignore — `.gcloudignore` file syntax and honoring commands
- https://cloud.google.com/sdk/gcloud/reference/topic/flags-file — `--flags-file=YAML_FILE` for portable complex flag values

## Product / SDK documentation
- https://cloud.google.com/sdk/docs — Google Cloud CLI documentation home
- https://cloud.google.com/sdk/docs/properties — Managing gcloud properties (per-config key/value pairs)
- https://cloud.google.com/sdk/docs/configurations — Managing named configurations (multi-project / multi-account workflows)
