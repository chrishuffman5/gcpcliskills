# gcloud looker regions

manage Looker regions

### `gcloud looker regions list`

List Looker regions

List all available Looker regions.

**Synopsis:**
```
gcloud looker regions list [--filter=EXPRESSION] [--limit=LIMIT]
    [--page-size=PAGE_SIZE] [--sort-by=[FIELD,...]] [--uri]
    [GCLOUD_WIDE_FLAG ...]
```

**Examples:**
```bash
To list all available Looker regions, run:

    $ gcloud looker regions list
```

[Official reference](https://cloud.google.com/sdk/gcloud/reference/looker/regions/list)
