# gcloud looker — sources

Official source URLs for the `gcloud looker` (Looker (Google Cloud core)) reference.

## gcloud CLI reference
- https://cloud.google.com/sdk/gcloud/reference/looker — `gcloud looker` command/flag reference (GA; backups, instances, operations, regions)
- https://cloud.google.com/sdk/gcloud/reference/alpha/looker — `gcloud alpha looker` reference

## Product documentation
- https://cloud.google.com/looker/docs/looker-core-overview — product docs home: editions, capabilities, and setup process
- https://cloud.google.com/looker/docs/looker-core-instance-create — create an instance: prerequisites, required API, IAM roles, CLI commands
- https://cloud.google.com/looker/docs/looker-core-backup-restore — back up and restore instances (automatic 24h + manual backups, 30-day retention)
- https://cloud.google.com/looker/docs/looker-core-maintenance — maintenance windows and deny periods
- https://cloud.google.com/looker/docs/looker-core-instance-setup — post-creation setup: LookML, authentication, user management
- https://cloud.google.com/iam/docs/roles-permissions/looker — IAM predefined roles (`roles/looker.*`) and permissions
- https://cloud.google.com/looker/docs/reference/looker-api/latest — Looker Application API reference (v4.0, JSON REST)
