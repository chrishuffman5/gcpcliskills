# gcloud migration — command index

the root group for various Cloud Migration teams

- `gcloud migration vms image-imports create` — import Virtual Disk images to Google Compute Engine
- `gcloud migration vms image-imports delete` — delete an Image Import resource
- `gcloud migration vms image-imports describe` — describe an Image Import
- `gcloud migration vms image-imports list` — list Image Imports
- `gcloud migration vms machine-image-imports create` — import machine images to Google Compute Engine
- `gcloud migration vms machine-image-imports delete` — delete an Image Import resource
- `gcloud migration vms machine-image-imports describe` — describe an Image Import
- `gcloud migration vms machine-image-imports list` — list Image Imports
- `gcloud migration vms target-projects list` — list Target Projects
