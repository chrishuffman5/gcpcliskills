# gcloud artifacts go

manage Artifact Registry Go modules

### `gcloud artifacts go auth`

Print authentication commands for the GOAUTH environment variable

This command implements the GOAUTH credential provider command introduced
in Go 1.24. For more details about the GOAUTH environment variable, see
https://pkg.go.dev/cmd/go#hdr-GOAUTH_environment_variable. When you
configure the GOAUTH environment variable for repositories, Artifact
Registry looks for credentials in the following order:

  o Application Default Credentials (ADC)
  o Credentials provided by the Google Cloud CLI, including user
    credentials from the command gcloud auth application-default login.

**Synopsis:**
```
gcloud artifacts go auth [URL ...] --location=LOCATION
    [--json-key=JSON_KEY] [GCLOUD_WIDE_FLAG ...]
```

**Positional arguments:**
```
[URL ...]
   A URL generated by Go to set up authentication.
```

**Required flags:**

| Flag | Value | Default | Description |
|------|-------|---------|-------------|
| `--location` | LOCATION |  | The location of the repository to print commands for. |


**Optional flags:**

| Flag | Value | Default | Description |
|------|-------|---------|-------------|
| `--json-key` | JSON_KEY |  | The path to the JSON key file to use for authentication. If not specified, the authentication commands printed will use the token from the logged in user. |


**Examples:**
```bash
To configure the GOAUTH environment variable for repositories in
us-central1 and use your credentials:

    $ export GOAUTH="gcloud artifacts go auth --location=us-central1"

To configure the GOAUTH environment variable for repositories in
us-central1 and use the credentials from a service account:

    $ export \
      GOAUTH="gcloud artifacts go auth --location=us-central1 \
    --json-key=path/to/key.json"
```

[Official reference](https://cloud.google.com/sdk/gcloud/reference/artifacts/go/auth)

### `gcloud artifacts go upload`

Upload a Go module to an artifact repository

Upload a Go module to an artifact repository.

**Synopsis:**
```
gcloud artifacts go upload --module-path=MODULE_PATH --version=VERSION
    [--async] [--source=SOURCE; default="."]
    [--location=LOCATION --repository=REPOSITORY] [GCLOUD_WIDE_FLAG ...]
```

**Required flags:**

| Flag | Value | Default | Description |
|------|-------|---------|-------------|
| `--module-path` | MODULE_PATH |  | The module path of the Go module. |
| `--version` | VERSION |  | The version of the Go module. |


**Optional flags:**

| Flag | Value | Default | Description |
|------|-------|---------|-------------|
| `--async` |  |  | Return immediately, without waiting for the operation in progress to complete. |
| `--source` | SOURCE |  | The root directory of the go module source code, defaults to the current directory. |


**Examples:**
```bash
To upload version v0.1.0 of a Go module located in /path/to/code/ to a
repository in "us-central1":

    $ gcloud artifacts go upload --location=us-central1 \
      --project=myproject --repository=myrepo \
      --module-path=the/module/path --version=v0.1.0 \
      --source=/path/to/code
```

[Official reference](https://cloud.google.com/sdk/gcloud/reference/artifacts/go/upload)
