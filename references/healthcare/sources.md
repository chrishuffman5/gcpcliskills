# gcloud healthcare — sources

Official source URLs for the Cloud Healthcare API reference. These are the citation record for the router SKILL.md.

## gcloud CLI reference
- https://cloud.google.com/sdk/gcloud/reference/healthcare — GA command group reference for all `gcloud healthcare` subgroups.
- https://cloud.google.com/sdk/gcloud/reference/beta/healthcare — beta reference; adds the `nlp` subgroup.
- https://cloud.google.com/sdk/gcloud/reference/beta/healthcare/nlp — beta-only `analyze-entities` command.

## Product documentation
- https://cloud.google.com/healthcare-api/docs — Cloud Healthcare API product documentation home.
- https://cloud.google.com/healthcare-api/docs/quickstart — quickstart: enable API, grant roles, create a dataset and stores.
- https://cloud.google.com/healthcare-api/docs/how-tos/datasets — how-to: create, update, describe, list, delete datasets.
- https://cloud.google.com/healthcare-api/docs/how-tos/fhir — how-to: create and manage FHIR stores (DSTU2/STU3/R4).
- https://cloud.google.com/healthcare-api/docs/access-control — IAM roles and permissions for all Healthcare resource types.
