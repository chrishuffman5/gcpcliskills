# gcloud api-gateway — command index

manage Cloud API Gateway resources

- `gcloud api-gateway api-configs create` — add a new config to an API
- `gcloud api-gateway api-configs delete` — deletes a config from an API
- `gcloud api-gateway api-configs describe` — show details about a specific API config
- `gcloud api-gateway api-configs list` — list configs for an API
- `gcloud api-gateway api-configs update` — update an API Gateway API config
- `gcloud api-gateway apis add-iam-policy-binding` — add IAM policy binding to a gateway
- `gcloud api-gateway apis create` — create a new API
- `gcloud api-gateway apis delete` — deletes an API
- `gcloud api-gateway apis describe` — show details about a specific API
- `gcloud api-gateway apis get-iam-policy` — get the IAM policy for an API
- `gcloud api-gateway apis list` — list APIs
- `gcloud api-gateway apis remove-iam-policy-binding` — remove IAM policy binding to a gateway
- `gcloud api-gateway apis update` — update an API Gateway API
- `gcloud api-gateway gateways add-iam-policy-binding` — add IAM policy binding to a gateway
- `gcloud api-gateway gateways create` — create a new gateway
- `gcloud api-gateway gateways delete` — delete an API Gateway
- `gcloud api-gateway gateways describe` — show details about a specific gateway
- `gcloud api-gateway gateways get-iam-policy` — get the IAM policy for a gateway
- `gcloud api-gateway gateways list` — list API Gateways
- `gcloud api-gateway gateways remove-iam-policy-binding` — remove IAM policy binding from a gateway
- `gcloud api-gateway gateways update` — update an API Gateway
- `gcloud api-gateway operations cancel` — cancel a Cloud API Gateway operation
- `gcloud api-gateway operations describe` — show details about the Cloud API Gateway operation
- `gcloud api-gateway operations list` — list API Gateway operations
- `gcloud api-gateway operations wait` — wait for a Cloud API Gateway operation to complete
