# gcloud assured — command index

read and manipulate Assured Workloads data controls

- `gcloud assured operations describe` — describe Assured Workloads operations
- `gcloud assured operations list` — list all Assured Workloads operations that belong to a given parent organization
- `gcloud assured workloads create` — create a new Assured Workloads environment
- `gcloud assured workloads delete` — delete Assured Workloads environment
- `gcloud assured workloads describe` — describe Assured Workloads environment
- `gcloud assured workloads enable-resource-monitoring` — enables Resource Monitoring for an Assured Workloads environment
- `gcloud assured workloads list` — list all Assured Workloads environments that belong to a given parent organization
- `gcloud assured workloads update` — update Assured Workloads environments
- `gcloud assured workloads violations acknowledge` — acknowledge an existing Assured Workloads compliance violation
- `gcloud assured workloads violations describe` — describe an Assured Workloads compliance violation
- `gcloud assured workloads violations list` — list all Assured Workloads violations that belong to a assured workloads environment
