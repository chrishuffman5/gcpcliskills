# gcloud active-directory — command index

manage Managed Microsoft AD resources

- `gcloud active-directory domains create` — create a Managed Microsoft AD domain
- `gcloud active-directory domains delete` — delete a managed Microsoft Active Directory domain
- `gcloud active-directory domains describe` — describe a Managed Microsoft AD domain
- `gcloud active-directory domains describe-ldaps-settings` — describe the LDAPS settings of a Managed Microsoft AD domain
- `gcloud active-directory domains extend-schema` — initiate schema extension for a Managed Microsoft AD domain
- `gcloud active-directory domains get-iam-policy` — describe the IAM policy for a Managed Microsoft AD domain
- `gcloud active-directory domains list` — list Managed Microsoft AD domains
- `gcloud active-directory domains reset-admin-password` — reset the admin password for a Managed Microsoft AD domain
- `gcloud active-directory domains restore` — restore a domain from the specified backup
- `gcloud active-directory domains set-iam-policy` — set the IAM policy for a Managed Microsoft AD domain
- `gcloud active-directory domains update` — update a Managed Microsoft AD domain
- `gcloud active-directory domains update-ldaps-settings` — update the LDAPS settings for a domain
- `gcloud active-directory domains backups create` — create a Managed Microsoft AD domain backup
- `gcloud active-directory domains backups delete` — delete a Managed Microsoft AD domain backup
- `gcloud active-directory domains backups describe` — describe a Managed Microsoft AD domain backup
- `gcloud active-directory domains backups list` — list all Managed Microsoft AD domain backups
- `gcloud active-directory domains backups update` — update a Managed Microsoft AD domain backup
- `gcloud active-directory domains trusts create` — create a Microsoft Active Directory Trust between a Managed Microsoft AD domain and another domain
- `gcloud active-directory domains trusts delete` — delete an Active Directory Trust between a Managed Microsoft AD domain and a target domain
- `gcloud active-directory domains trusts update` — update target DNS IP addresses for a Managed Microsoft AD trust
- `gcloud active-directory domains trusts validate-state` — validate the state of a Managed Microsoft AD trust
- `gcloud active-directory operations cancel` — cancel a Managed Microsoft AD operation
- `gcloud active-directory operations describe` — describe a Managed Microsoft AD operation
- `gcloud active-directory operations list` — list Managed Microsoft AD operations
- `gcloud active-directory peerings create` — create a Managed Microsoft Active Directory domain peering
- `gcloud active-directory peerings delete` — delete a Managed Microsoft Active Directory domain peering
- `gcloud active-directory peerings describe` — describe a Managed Microsoft Active Directory domain peering
- `gcloud active-directory peerings list` — list all Managed Microsoft Active Directory domain peerings
- `gcloud active-directory peerings update` — update a Managed Microsoft Active Directory domain peering
