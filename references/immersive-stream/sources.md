# Sources — gcloud immersive-stream (Immersive Stream for XR)

Citation record for the `immersive-stream` service reference. The command surface
is authoritative from the local reference files generated from `gcloud --help`
(v552.0.0 / present through gcloud 570.0.0). The upstream product documentation has
been deprecated and removed: all `cloud.google.com/immersive-stream/xr/docs/*` URLs
return HTTP 301 to the generic AI/ML landing page, and the published gcloud reference
pages return HTTP 404. URLs are retained below for reference with their current status.
