# gcloud scheduler — command index

manage Cloud Scheduler jobs and schedules

- `gcloud scheduler cmek-config describe` — get CMEK configuration for Cloud Scheduler in the specified location
- `gcloud scheduler cmek-config update` — update CMEK configuration for Cloud Scheduler in the specified location
- `gcloud scheduler jobs delete` — delete a job
- `gcloud scheduler jobs describe` — show details about a job
- `gcloud scheduler jobs list` — list jobs
- `gcloud scheduler jobs pause` — pause the execution of a job
- `gcloud scheduler jobs resume` — resume execution of a paused job
- `gcloud scheduler jobs run` — trigger an on-demand execution of a job
- `gcloud scheduler jobs create app-engine` — create a Cloud Scheduler job with an App Engine target
- `gcloud scheduler jobs create http` — create a Cloud Scheduler job that triggers an action via HTTP
- `gcloud scheduler jobs create pubsub` — create a Cloud Scheduler job with a Pub/Sub target
- `gcloud scheduler jobs update app-engine` — update a Cloud Scheduler job with an App Engine target
- `gcloud scheduler jobs update http` — update a Cloud Scheduler job that triggers an action via HTTP
- `gcloud scheduler jobs update pubsub` — update a Cloud Scheduler job with a Pub/Sub target
- `gcloud scheduler locations describe` — show details about a location
- `gcloud scheduler locations list` — lists the locations where Cloud Scheduler is available
- `gcloud scheduler operations describe` — show the latest status of an operation
