# Sources — gcloud cloud-shell

Citation record for the `gcloud cloud-shell` (Cloud Shell) service reference.

## gcloud CLI reference
- https://cloud.google.com/sdk/gcloud/reference/cloud-shell — gcloud cloud-shell command reference (ssh, scp, get-mount-command)
- https://cloud.google.com/sdk/gcloud/reference/beta/cloud-shell — beta channel reference
- https://cloud.google.com/sdk/gcloud/reference/alpha/cloud-shell — alpha channel reference

## Product documentation
- https://cloud.google.com/shell/docs — Cloud Shell product documentation home (product docs home)
- https://cloud.google.com/shell/docs/using-cloud-shell — Using Cloud Shell: terminal, editor, storage modes, web preview
- https://cloud.google.com/shell/docs/how-cloud-shell-works — Architecture: per-user VMs, Docker container, 5 GB persistent $HOME
- https://cloud.google.com/shell/docs/run-gcloud-commands — Quickstart: run gcloud commands with Cloud Shell
- https://cloud.google.com/shell/docs/limitations — Quotas and limits (50 hr/week, 12 hr max session, 40 min inactivity timeout)
- https://cloud.google.com/shell/docs/reference/rest — Cloud Shell REST API reference (service: cloudshell.googleapis.com)
