# gcloud workflows — command index

manage your Cloud Workflows resources

- `gcloud workflows delete` — delete a workflow
- `gcloud workflows deploy` — create or update a workflow
- `gcloud workflows describe` — show metadata for a workflow
- `gcloud workflows execute` — execute a workflow
- `gcloud workflows list` — list workflows
- `gcloud workflows run` — execute a workflow and wait for the execution to complete
- `gcloud workflows executions cancel` — cancel a workflow execution
- `gcloud workflows executions describe` — show metadata for a workflow execution
- `gcloud workflows executions describe-last` — show metadata for the last cached workflow execution
- `gcloud workflows executions list` — list workflow executions
- `gcloud workflows executions wait` — wait for an execution to complete
- `gcloud workflows executions wait-last` — wait for the last cached workflow execution to complete
