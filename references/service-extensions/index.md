# gcloud service-extensions — command index

manage Service Extensions resources

- `gcloud service-extensions authz-extensions delete` — delete an AuthzExtension resource
- `gcloud service-extensions authz-extensions describe` — describe an AuthzExtension resource
- `gcloud service-extensions authz-extensions import` — import an AuthzExtension resource
- `gcloud service-extensions authz-extensions list` — list AuthzExtension resources
- `gcloud service-extensions lb-edge-extensions delete` — delete an LbEdgeExtension resource
- `gcloud service-extensions lb-edge-extensions describe` — describe an LbEdgeExtension resource
- `gcloud service-extensions lb-edge-extensions import` — import an LbEdgeExtension resource
- `gcloud service-extensions lb-edge-extensions list` — list LbEdgeExtension resources
- `gcloud service-extensions lb-route-extensions delete` — delete an LbRouteExtension resource
- `gcloud service-extensions lb-route-extensions describe` — describe an LbRouteExtension resource
- `gcloud service-extensions lb-route-extensions import` — import an LbRouteExtension resource
- `gcloud service-extensions lb-route-extensions list` — list LbRouteExtension resources
- `gcloud service-extensions lb-traffic-extensions delete` — delete an LbTrafficExtension resource
- `gcloud service-extensions lb-traffic-extensions describe` — describe an LbTrafficExtension resource
- `gcloud service-extensions lb-traffic-extensions import` — import an LbTrafficExtension resource
- `gcloud service-extensions lb-traffic-extensions list` — list LbTrafficExtension resources
- `gcloud service-extensions wasm-plugin-versions create` — create a WasmPluginVersion resource
- `gcloud service-extensions wasm-plugin-versions delete` — delete a WasmPluginVersion resource
- `gcloud service-extensions wasm-plugin-versions describe` — show details about a WasmPluginVersion resource
- `gcloud service-extensions wasm-plugin-versions list` — list all WasmPluginVersion resources for a WasmPlugin
- `gcloud service-extensions wasm-plugins create` — create a WasmPlugin resource
- `gcloud service-extensions wasm-plugins delete` — delete a WasmPlugin resource
- `gcloud service-extensions wasm-plugins describe` — show details about a WasmPlugin resource
- `gcloud service-extensions wasm-plugins list` — list all WasmPlugin resources
- `gcloud service-extensions wasm-plugins update` — update a WasmPlugin resource
