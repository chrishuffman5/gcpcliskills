# gcloud memcache — command index

manage Cloud Memorystore Memcached resources

- `gcloud memcache instances apply-parameters` — apply parameter update to nodes in a Memorystore Memcached instance
- `gcloud memcache instances create` — create a Memorystore Memcached instance
- `gcloud memcache instances delete` — delete a Memorystore Memcached instance
- `gcloud memcache instances describe` — display metadata for a Memorystore Memcached instance
- `gcloud memcache instances list` — list Memorystore Memcached instances
- `gcloud memcache instances reschedule-maintenance` — reschedule maintenance window for a Memcache instance
- `gcloud memcache instances update` — update a Memorystore Memcached instance
- `gcloud memcache instances upgrade` — upgrade memcache instance to a newer memcached version
- `gcloud memcache operations delete` — delete a Memorystore Memcached operation
- `gcloud memcache operations describe` — display metadata for a Memorystore Memcached operation
- `gcloud memcache operations list` — list Memorystore Memcached operations
- `gcloud memcache regions describe` — display metadata for a Memorystore Memcached region
- `gcloud memcache regions list` — list Memorystore Memcached regions
