# gcloud sql tiers

provide a command to list tiers

### `gcloud sql tiers list`

Lists all available service tiers for Google Cloud SQL

Lists all available service tiers for Google Cloud SQL.

**Synopsis:**
```
gcloud sql tiers list [--show-edition] [--filter=EXPRESSION]
    [--limit=LIMIT] [--page-size=PAGE_SIZE] [--sort-by=[FIELD,...]] [--uri]
    [GCLOUD_WIDE_FLAG ...]
```

**Optional flags:**

| Flag | Value | Default | Description |
|------|-------|---------|-------------|
| `--show-edition` |  |  | Show the edition field. |


[Official reference](https://cloud.google.com/sdk/gcloud/reference/sql/tiers/list)
