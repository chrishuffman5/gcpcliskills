# gcloud emulators — command index

set up your local development environment using emulators

- `gcloud emulators firestore start` — start a local Firestore emulator
- `gcloud emulators spanner env-init` — print the commands required to export Spanner emulator's env variables
- `gcloud emulators spanner notices` — print third-party notices for the local Cloud Spanner emulator
- `gcloud emulators spanner start` — start a local Cloud Spanner emulator
