# gcloud workspace-add-ons — command index

manage Google Workspace Add-ons resources

- `gcloud workspace-add-ons get-authorization` — gets the authorization information for deployments in a given project
- `gcloud workspace-add-ons deployments create` — create a Google Workspace Add-ons deployment
- `gcloud workspace-add-ons deployments delete` — delete a Google Workspace Add-ons deployment
- `gcloud workspace-add-ons deployments describe` — describe a Google Workspace Add-ons deployment
- `gcloud workspace-add-ons deployments install` — install a Google Workspace Add-ons deployment
- `gcloud workspace-add-ons deployments install-status` — get the install status of a Google Workspace Add-ons deployment
- `gcloud workspace-add-ons deployments list` — list Google Workspace Add-ons deployments
- `gcloud workspace-add-ons deployments replace` — replace a Google Workspace Add-ons deployment
- `gcloud workspace-add-ons deployments uninstall` — uninstall a Google Workspace Add-ons deployment
