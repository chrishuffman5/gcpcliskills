# gcloud scheduler — sources

Official source URLs backing this reference (verified via WebFetch during research).

## gcloud CLI reference
- https://cloud.google.com/sdk/gcloud/reference/scheduler — gcloud CLI reference for all `scheduler` commands.
- https://cloud.google.com/sdk/gcloud/reference/beta/scheduler — beta surface reference.

- https://cloud.google.com/scheduler/docs — Cloud Scheduler docs home.
- https://cloud.google.com/scheduler/docs/overview — concepts: target types, cron format, retry, at-least-once delivery.
- https://cloud.google.com/scheduler/docs/quickstart — quickstart: enable APIs, create a Pub/Sub job.
- https://cloud.google.com/scheduler/docs/configuring/cron-job-schedules — cron schedule format (unix-cron + groc).
- https://cloud.google.com/scheduler/docs/configuring/retry-jobs — retry configuration (attempts, backoff, max doublings).
- https://cloud.google.com/scheduler/docs/http-target-auth — HTTP target auth (OIDC vs OAuth2).
- https://cloud.google.com/scheduler/docs/access-control — IAM roles (Admin, Viewer, Job Runner, Service Agent).
