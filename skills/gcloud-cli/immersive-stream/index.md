# gcloud immersive-stream — command index

manage Immersive Stream resources

- `gcloud immersive-stream xr contents build` — build an Immersive Stream for XR content resource
- `gcloud immersive-stream xr contents create` — create an Immersive Stream for XR content resource
- `gcloud immersive-stream xr contents delete` — delete an Immersive Stream for XR content resource
- `gcloud immersive-stream xr contents describe` — describe a specific Immersive Stream for XR content resource
- `gcloud immersive-stream xr contents list` — list Immersive Stream for XR content resources
- `gcloud immersive-stream xr contents update` — update an Immersive Stream for XR content resource
- `gcloud immersive-stream xr instances create` — create an Immersive Stream for XR service instance
- `gcloud immersive-stream xr instances delete` — delete an Immersive Stream for XR service instance
- `gcloud immersive-stream xr instances describe` — describe a specific Immersive Stream for XR service instance
- `gcloud immersive-stream xr instances list` — list Immersive Stream for XR service instances
- `gcloud immersive-stream xr instances update` — update an Immersive Stream for XR service instance
- `gcloud immersive-stream xr operations describe` — get description of a long-running Immersive Stream for XR operation
- `gcloud immersive-stream xr operations list` — list Immersive Stream for XR operations
- `gcloud immersive-stream xr operations wait` — poll long-running Immersive Stream for XR operation until it completes
