# gcloud vector-search — command index

manage Vector Search data objects

- `gcloud vector-search collections create` — create a collection
- `gcloud vector-search collections delete` — delete a collection
- `gcloud vector-search collections describe` — describe a collection
- `gcloud vector-search collections export-data-objects` — export data objects from a collection
- `gcloud vector-search collections import-data-objects` — import data objects into a collection
- `gcloud vector-search collections list` — list collections
- `gcloud vector-search collections update` — update a collection
- `gcloud vector-search collections data-objects aggregate` — aggregate data objects
- `gcloud vector-search collections data-objects batch-create` — create a batch of data objects
- `gcloud vector-search collections data-objects batch-delete` — delete a batch of data objects
- `gcloud vector-search collections data-objects batch-search` — batch search data objects from a Vector Search collection
- `gcloud vector-search collections data-objects batch-update` — update a batch of data objects
- `gcloud vector-search collections data-objects create` — create a data object
- `gcloud vector-search collections data-objects delete` — delete a data object
- `gcloud vector-search collections data-objects describe` — describe a data object
- `gcloud vector-search collections data-objects query` — query data objects from a Vector Search collection
- `gcloud vector-search collections data-objects search` — search data objects from a Vector Search collection
- `gcloud vector-search collections data-objects update` — update a data object
- `gcloud vector-search collections indexes create` — create an index
- `gcloud vector-search collections indexes delete` — delete an index
- `gcloud vector-search collections indexes describe` — describe an index
- `gcloud vector-search collections indexes list` — list indexes
- `gcloud vector-search operations cancel` — cancel an operation
- `gcloud vector-search operations delete` — delete an operation
- `gcloud vector-search operations describe` — describe an operation
- `gcloud vector-search operations list` — list operations
- `gcloud vector-search operations wait` — wait for an operation to complete
