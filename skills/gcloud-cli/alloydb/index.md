# gcloud alloydb — command index

create and manage AlloyDB databases

- `gcloud alloydb backups create` — creates a new AlloyDB backup within a given project
- `gcloud alloydb backups delete` — deletes an AlloyDB backup within a given project
- `gcloud alloydb backups describe` — describes an AlloyDB backup in a given project and region
- `gcloud alloydb backups list` — lists AlloyDB backups in a given project
- `gcloud alloydb clusters create` — create a new AlloyDB cluster within a given project
- `gcloud alloydb clusters create-secondary` — create a new AlloyDB SECONDARY cluster within a given project
- `gcloud alloydb clusters delete` — delete an AlloyDB cluster in a given region
- `gcloud alloydb clusters describe` — describe an AlloyDB cluster in a given project and region
- `gcloud alloydb clusters export` — export data from an AlloyDB cluster to Google Cloud Storage
- `gcloud alloydb clusters import` — import data into an AlloyDB cluster from Google Cloud Storage
- `gcloud alloydb clusters list` — list AlloyDB clusters in a given project and region
- `gcloud alloydb clusters migrate-cloud-sql` — migrate Cloud SQL instance to an AlloyDB cluster using an existing Cloud SQL backup
- `gcloud alloydb clusters promote` — promote an AlloyDB SECONDARY cluster in a given project and region
- `gcloud alloydb clusters restore` — restore an AlloyDB cluster from a given backup or a source cluster and a timestamp
- `gcloud alloydb clusters switchover` — switchover an AlloyDB SECONDARY cluster in a given project and region
- `gcloud alloydb clusters update` — update an AlloyDB cluster within a given project and region
- `gcloud alloydb clusters upgrade` — upgrade an AlloyDB cluster within a given project and region
- `gcloud alloydb instances create` — creates a new AlloyDB instance within a given cluster
- `gcloud alloydb instances create-secondary` — creates a new AlloyDB SECONDARY instance within a given cluster
- `gcloud alloydb instances delete` — deletes an AlloyDB instance within a given cluster
- `gcloud alloydb instances describe` — describes an AlloyDB instance within a given cluster
- `gcloud alloydb instances failover` — failover an AlloyDB instance within a given cluster
- `gcloud alloydb instances inject-fault` — inject fault on an AlloyDB instance within a given cluster
- `gcloud alloydb instances list` — lists AlloyDB instances in a given cluster
- `gcloud alloydb instances restart` — restarts an AlloyDB instance within a given cluster
- `gcloud alloydb instances update` — updates an AlloyDB instance within a given cluster
- `gcloud alloydb operations cancel` — cancels an AlloyDB operation
- `gcloud alloydb operations delete` — deletes an AlloyDB operation
- `gcloud alloydb operations describe` — describes an AlloyDB operation
- `gcloud alloydb operations list` — lists AlloyDB operations
- `gcloud alloydb users create` — creates a user in a given cluster
- `gcloud alloydb users delete` — deletes an AlloyDB user in a given cluster
- `gcloud alloydb users list` — lists AlloyDB users in a given cluster
- `gcloud alloydb users set-password` — update an AlloyDB user's password within a given cluster and region
- `gcloud alloydb users set-roles` — update an AlloyDB user's database roles within a given cluster and region
- `gcloud alloydb users set-superuser` — update an AlloyDB user's superuser role within a given cluster and region
