# gcloud datastore — command index

manage your Cloud Datastore resources

- `gcloud datastore export` — export Cloud Datastore entities to Google Cloud Storage
- `gcloud datastore import` — import Cloud Datastore entities from Google Cloud Storage
- `gcloud datastore indexes cleanup` — remove unused datastore indexes based on your local index configuration
- `gcloud datastore indexes create` — create new datastore indexes based on your local index configuration
- `gcloud datastore indexes describe` — show details about an Cloud Datastore index
- `gcloud datastore indexes list` — list Cloud Datastore indexes
- `gcloud datastore operations cancel` — cancel a currently-running Cloud Datastore admin operation
- `gcloud datastore operations delete` — delete a completed Cloud Datastore admin operation
- `gcloud datastore operations describe` — retrieves information about a Cloud Datastore admin operation
- `gcloud datastore operations list` — list pending Cloud Datastore admin operations and their status
