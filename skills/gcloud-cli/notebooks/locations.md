# gcloud notebooks locations

view locations available for a project

### `gcloud notebooks locations list`

Request for listing locations

Request for listing locations.

**Synopsis:**
```
gcloud notebooks locations list [--filter=EXPRESSION] [--limit=LIMIT]
    [--page-size=PAGE_SIZE] [--sort-by=[FIELD,...]] [--uri]
    [GCLOUD_WIDE_FLAG ...]
```

**Examples:**
```bash
To list locations, run:        $ gcloud notebooks locations list
```

[Official reference](https://cloud.google.com/sdk/gcloud/reference/notebooks/locations/list)
