# gcloud source-manager locations

manage Secure Source Manager locations

### `gcloud source-manager locations list`

List Secure Source Manager locations

List all locations where Secure Source Manager is available.

**Synopsis:**
```
gcloud source-manager locations list [--filter=EXPRESSION] [--limit=LIMIT]
    [--page-size=PAGE_SIZE] [--sort-by=[FIELD,...]] [--uri]
    [GCLOUD_WIDE_FLAG ...]
```

**Examples:**
```bash
To list all locations where Secure Source Manager is available for the
current project, run:

    $ gcloud source-manager locations list
```

[Official reference](https://cloud.google.com/sdk/gcloud/reference/source-manager/locations/list)
