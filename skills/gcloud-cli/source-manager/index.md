# gcloud source-manager — command index

manage Secure Source Manager resources

- `gcloud source-manager instances add-iam-policy-binding` — add an IAM policy binding to a Secure Source Manager instance
- `gcloud source-manager instances create` — create a Secure Source Manager instance
- `gcloud source-manager instances delete` — delete a Secure Source Manager instance
- `gcloud source-manager instances describe` — describe a Secure Source Manager instance
- `gcloud source-manager instances get-iam-policy` — get the IAM policy for a Secure Source Manager instance
- `gcloud source-manager instances list` — list Secure Source Manager instances
- `gcloud source-manager instances remove-iam-policy-binding` — remove an IAM policy binding to a Secure Source Manager instance
- `gcloud source-manager instances set-iam-policy` — set the IAM policy for a Secure Source Manager instance
- `gcloud source-manager locations list` — list Secure Source Manager locations
- `gcloud source-manager operations describe` — describe a Secure Source Manager operation
- `gcloud source-manager operations list` — list Secure Source Manager operations
- `gcloud source-manager repos add-iam-policy-binding` — add an IAM policy binding to a Secure Source Manager repository
- `gcloud source-manager repos create` — create a Secure Source Manager repository
- `gcloud source-manager repos delete` — delete a Secure Source Manager repository
- `gcloud source-manager repos describe` — describe a Secure Source Manager repository
- `gcloud source-manager repos get-iam-policy` — get the IAM policy for a Secure Source Manager repository
- `gcloud source-manager repos list` — list all repositories under a Secure Source Manager instance
- `gcloud source-manager repos remove-iam-policy-binding` — remove an IAM policy binding from a Secure Source Manager repository
- `gcloud source-manager repos set-iam-policy` — set the IAM policy for a Secure Source Manager repository
- `gcloud source-manager repos update` — update a Secure Source Manager repository
