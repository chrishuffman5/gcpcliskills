# gcloud organizations — command index

create and manage Google Cloud Platform Organizations

- `gcloud organizations add-iam-policy-binding` — add IAM policy binding for an organization
- `gcloud organizations describe` — show metadata for an organization
- `gcloud organizations get-iam-policy` — get IAM policy for an organization
- `gcloud organizations list` — list organizations accessible by the active account
- `gcloud organizations remove-iam-policy-binding` — remove IAM policy binding for an organization
- `gcloud organizations set-iam-policy` — set IAM policy for an organization
