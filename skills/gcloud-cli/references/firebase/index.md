# gcloud firebase — command index

work with Google Firebase

- `gcloud firebase test android list-device-capacities` — list capacity information for Android models & versions
- `gcloud firebase test android run` — invoke a test in Firebase Test Lab for Android and view test results
- `gcloud firebase test android locales describe` — describe an Android locale
- `gcloud firebase test android locales list` — list all Android locales available for testing internationalized apps
- `gcloud firebase test android models describe` — describe an Android model
- `gcloud firebase test android models list` — list all Android models available for testing
- `gcloud firebase test android versions describe` — describe an Android OS version
- `gcloud firebase test android versions list` — list all Android OS versions available for testing
- `gcloud firebase test ios list-device-capacities` — list capacity information for iOS models & versions
- `gcloud firebase test ios run` — invoke a test in Firebase Test Lab for iOS and view test results
- `gcloud firebase test ios locales describe` — describe an iOS locale
- `gcloud firebase test ios locales list` — list all iOS locales available for testing internationalized apps
- `gcloud firebase test ios models describe` — describe an iOS model
- `gcloud firebase test ios models list` — list all iOS models available for testing
- `gcloud firebase test ios versions describe` — describe an iOS operating system version
- `gcloud firebase test ios versions list` — list all iOS versions available for testing
- `gcloud firebase test network-profiles describe` — describe a network profile
- `gcloud firebase test network-profiles list` — list all network profiles available for testing
