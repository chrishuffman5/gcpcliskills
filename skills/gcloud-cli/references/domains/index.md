# gcloud domains — command index

manage domains for your Google Cloud projects

- `gcloud domains list-user-verified` — lists the user's verified domains
- `gcloud domains verify` — verifies a domain via an in-browser workflow
- `gcloud domains registrations delete` — delete a Cloud Domains registration
- `gcloud domains registrations describe` — describe an existing Cloud Domains registration
- `gcloud domains registrations get-register-parameters` — get register parameters (including availability) of a specific domain
- `gcloud domains registrations initiate-push-transfer` — initiates the push transfer process
- `gcloud domains registrations list` — list Cloud Domains registrations
- `gcloud domains registrations register` — register a new domain
- `gcloud domains registrations renew-domain` — renew a recently expired Cloud Domains registration
- `gcloud domains registrations search-domains` — search for available domains
- `gcloud domains registrations update` — update a Cloud Domains registration
- `gcloud domains registrations authorization-code get` — get authorization code of a specific Cloud Domains registration
- `gcloud domains registrations authorization-code reset` — resets authorization code of a specific Cloud Domains registration
- `gcloud domains registrations configure contacts` — configure contact settings of a Cloud Domains registration
- `gcloud domains registrations configure dns` — configure DNS settings of a Cloud Domains registration
- `gcloud domains registrations configure management` — configure management settings of a Cloud Domains registration
- `gcloud domains registrations google-domains-dns export-dns-record-sets` — export your registration's Google Domains DNS zone's record-sets into a file
- `gcloud domains registrations google-domains-dns get-forwarding-config` — get forwarding configuration of a specific Cloud Domains registration
- `gcloud domains registrations operations describe` — show details about a Cloud Domains operation
- `gcloud domains registrations operations list` — list Cloud Domains operations
- `gcloud domains registrations operations wait` — wait for asynchronous operation to complete
