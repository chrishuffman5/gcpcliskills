# gcloud vmware locations

list locations in Google Cloud VMware Engine

### `gcloud vmware locations list`

List Google Cloud VMware Engine locations

List supported VMware Engine locations.

**Synopsis:**
```
gcloud vmware locations list [--filter=EXPRESSION] [--limit=LIMIT]
    [--page-size=PAGE_SIZE] [--sort-by=[FIELD,...]] [--uri]
    [GCLOUD_WIDE_FLAG ...]
```

**Examples:**
```bash
To list VMware Engine locations, run:

    $ gcloud vmware locations list
```

[Official reference](https://cloud.google.com/sdk/gcloud/reference/vmware/locations/list)
