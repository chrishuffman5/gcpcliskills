# gcloud apigee — command index

manage Apigee resources

- `gcloud apigee apis deploy` — deploy an API proxy to an environment
- `gcloud apigee apis describe` — describe an Apigee API proxy
- `gcloud apigee apis list` — list Apigee API proxies
- `gcloud apigee apis undeploy` — undeploy an Apigee API proxy from an environment
- `gcloud apigee applications describe` — describe an Apigee application
- `gcloud apigee applications list` — list Apigee applications
- `gcloud apigee deployments describe` — describe an Apigee API proxy deployment
- `gcloud apigee deployments list` — list Apigee API proxy deployments
- `gcloud apigee developers describe` — describe an Apigee developer
- `gcloud apigee developers list` — list Apigee developers by email address
- `gcloud apigee environments list` — list Apigee deployment environments
- `gcloud apigee organizations list` — list Apigee organizations and their paired Cloud Platform projects
- `gcloud apigee products create` — create an Apigee API product
- `gcloud apigee products delete` — delete an Apigee API product
- `gcloud apigee products describe` — describe an Apigee API product
- `gcloud apigee products list` — list Apigee API products
- `gcloud apigee products update` — update an existing Apigee API product
