# gcloud colab — command index

manage Colab Enterprise resources

- `gcloud colab executions create` — create an execution
- `gcloud colab executions delete` — delete an execution
- `gcloud colab executions describe` — describe an execution
- `gcloud colab executions list` — list your Colab Enterprise notebook execution jobs
- `gcloud colab runtime-templates add-iam-policy-binding` — add an IAM policy binding to a Colab Enterprise runtime template
- `gcloud colab runtime-templates create` — create a runtime template
- `gcloud colab runtime-templates delete` — delete a runtime template
- `gcloud colab runtime-templates describe` — describe a runtime template
- `gcloud colab runtime-templates get-iam-policy` — get IAM policy for a Colab Enterprise runtime template
- `gcloud colab runtime-templates list` — list your runtime templates
- `gcloud colab runtime-templates remove-iam-policy-binding` — remove an IAM policy binding from a Colab Enterprise runtime template
- `gcloud colab runtime-templates set-iam-policy` — set IAM policy for a Colab Enterprise runtime template as defined in a JSON or YAML file
- `gcloud colab runtimes create` — create a notebook runtime
- `gcloud colab runtimes delete` — delete a runtime
- `gcloud colab runtimes describe` — describe a runtime
- `gcloud colab runtimes list` — list your project's runtimes
- `gcloud colab runtimes start` — start a stopped runtime
- `gcloud colab runtimes stop` — stop a runtime
- `gcloud colab runtimes upgrade` — upgrade a runtime
- `gcloud colab schedules create` — create a schedule
- `gcloud colab schedules delete` — delete a schedule
- `gcloud colab schedules describe` — describe a schedule
- `gcloud colab schedules list` — list your Colab Enterprise notebook execution schedules
- `gcloud colab schedules pause` — pause a schedule
- `gcloud colab schedules resume` — resume a schedule
- `gcloud colab schedules update` — update a schedule
