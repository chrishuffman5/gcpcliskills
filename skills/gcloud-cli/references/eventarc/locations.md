# gcloud eventarc locations

explore locations available for Eventarc

### `gcloud eventarc locations list`

List locations available for Eventarc

List locations available for Eventarc.

**Synopsis:**
```
gcloud eventarc locations list [--filter=EXPRESSION] [--limit=LIMIT]
    [--page-size=PAGE_SIZE] [--sort-by=[FIELD,...]] [--uri]
    [GCLOUD_WIDE_FLAG ...]
```

**Examples:**
```bash
To list all locations, run:

    $ gcloud eventarc locations list
```
