# gcloud monitoring — command index

manage Cloud Monitoring dashboards

- `gcloud monitoring dashboards create` — create a new Cloud Monitoring dashboard
- `gcloud monitoring dashboards delete` — delete a Cloud Monitoring dashboard
- `gcloud monitoring dashboards describe` — describe a Cloud Monitoring dashboard
- `gcloud monitoring dashboards list` — list Cloud Monitoring dashboards
- `gcloud monitoring dashboards update` — update a Cloud Monitoring dashboard
- `gcloud monitoring policies create` — create a new alerting policy
- `gcloud monitoring policies delete` — delete a Cloud Monitoring alerting policy
- `gcloud monitoring policies describe` — describe an alerting policy
- `gcloud monitoring policies list` — list alerting policies
- `gcloud monitoring policies migrate` — migrate a Prometheus configuration file to Cloud Monitoring
- `gcloud monitoring policies update` — updates an alerting policy
- `gcloud monitoring policies conditions create` — create a condition in an alerting policy
- `gcloud monitoring policies conditions delete` — delete a condition in an alerting policy
- `gcloud monitoring policies conditions describe` — describe a condition in a Cloud Monitoring alerting policy
- `gcloud monitoring policies conditions update` — update a condition in an alerting policy
- `gcloud monitoring snoozes cancel` — cancels a snooze
- `gcloud monitoring snoozes create` — create a new snooze
- `gcloud monitoring snoozes describe` — describe a snooze
- `gcloud monitoring snoozes list` — list snoozes
- `gcloud monitoring snoozes update` — updates a snooze
- `gcloud monitoring uptime create` — create a new uptime check or synthetic monitor
- `gcloud monitoring uptime delete` — delete an uptime check or synthetic monitor
- `gcloud monitoring uptime describe` — describe an uptime check or synthetic monitor
- `gcloud monitoring uptime list-configs` — list uptime checks and synthetic monitors
- `gcloud monitoring uptime list-ips` — list uptime check server ips
- `gcloud monitoring uptime update` — update an existing uptime check or synthetic monitor
