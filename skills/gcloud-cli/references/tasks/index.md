# gcloud tasks — command index

manage Cloud Tasks queues and tasks

- `gcloud tasks buffer` — buffers a task into a queue
- `gcloud tasks create-app-engine-task` — create and add a task that targets App Engine
- `gcloud tasks create-http-task` — create and add a task that targets a HTTP endpoint
- `gcloud tasks delete` — delete a task from a queue
- `gcloud tasks describe` — show details about a task
- `gcloud tasks list` — list tasks
- `gcloud tasks run` — force a task to run now
- `gcloud tasks cmek-config describe` — get CMEK configuration for Cloud Tasks in the specified location
- `gcloud tasks cmek-config update` — enable, disable, or edit CMEK configuration for Cloud Tasks in the specified location
- `gcloud tasks locations describe` — show details about a location
- `gcloud tasks locations list` — lists the locations where Cloud Tasks is available
- `gcloud tasks queues add-iam-policy-binding` — add IAM policy binding for a tasks queue
- `gcloud tasks queues create` — create a Cloud Tasks queue
- `gcloud tasks queues delete` — delete a queue
- `gcloud tasks queues describe` — show details about a queue
- `gcloud tasks queues get-iam-policy` — get the IAM policy for a queue
- `gcloud tasks queues list` — list all queues
- `gcloud tasks queues pause` — pause a queue
- `gcloud tasks queues purge` — purge a queue by deleting all of its tasks
- `gcloud tasks queues remove-iam-policy-binding` — remove IAM policy binding of tasks queue
- `gcloud tasks queues resume` — request to resume a paused or disabled queue
- `gcloud tasks queues set-iam-policy` — set the IAM policy for a queue
- `gcloud tasks queues update` — update a Cloud Tasks queue
