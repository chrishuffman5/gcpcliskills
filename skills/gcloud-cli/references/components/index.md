# gcloud components — command index

list, install, update, or remove Google Cloud CLI components

- `gcloud components install` — install one or more Google Cloud CLI components
- `gcloud components list` — list the status of all Google Cloud CLI components
- `gcloud components reinstall` — reinstall the Google Cloud CLI with the same components you have now
- `gcloud components remove` — remove one or more installed components
- `gcloud components update` — update all of your installed components to the latest version
- `gcloud components repositories add` — add a new Trusted Tester component repository
- `gcloud components repositories list` — list any Trusted Tester component repositories you have registered
- `gcloud components repositories remove` — remove a registered Trusted Test component repository
