# gcloud iap — command index

manage IAP policies

- `gcloud iap oauth-brands create` — create a Cloud OAuth brand for the project
- `gcloud iap oauth-brands describe` — describe a Cloud OAuth brand
- `gcloud iap oauth-brands list` — list Cloud OAuth brands in the project
- `gcloud iap oauth-clients create` — create a Cloud IAP OAuth client in the project
- `gcloud iap oauth-clients delete` — delete a Cloud IAP OAuth client
- `gcloud iap oauth-clients describe` — describe a Cloud IAP OAuth client
- `gcloud iap oauth-clients list` — list Cloud IAP OAuth clients in the Cloud OAuth brand
- `gcloud iap oauth-clients reset-secret` — reset a Cloud IAP OAuth client secret
- `gcloud iap settings get` — get the setting for an IAP resource
- `gcloud iap settings set` — set the setting for an IAP resource
- `gcloud iap tcp dest-groups add-iam-policy-binding` — add IAM policy binding to an IAP TCP Tunnel Destination Group resource
- `gcloud iap tcp dest-groups create` — create the IAP TCP Destination Group resource
- `gcloud iap tcp dest-groups delete` — delete the IAP TCP Destination Group resource
- `gcloud iap tcp dest-groups describe` — describe the IAP TCP Destination Group resource
- `gcloud iap tcp dest-groups get-iam-policy` — get IAM policy for an IAP TCP Destination Group resource
- `gcloud iap tcp dest-groups list` — lists the IAP TCP Destination Group resource
- `gcloud iap tcp dest-groups remove-iam-policy-binding` — remove IAM policy binding from an IAP TCP Destination Group resource
- `gcloud iap tcp dest-groups set-iam-policy` — set the IAM policy for an IAP TCP Destination Group resource
- `gcloud iap tcp dest-groups update` — update the IAP TCP Destination Group resource
- `gcloud iap web add-iam-policy-binding` — add IAM policy binding to an IAP IAM resource
- `gcloud iap web disable` — disable Cloud Identity-Aware Proxy (Cloud IAP) on an IAP resource
- `gcloud iap web enable` — enable Cloud Identity-Aware Proxy (Cloud IAP) on an IAP resource
- `gcloud iap web get-iam-policy` — get IAM policy for an IAP IAM resource
- `gcloud iap web remove-iam-policy-binding` — remove IAM policy binding from an IAP IAM resource
- `gcloud iap web set-iam-policy` — set the IAM policy for an IAP IAM resource
