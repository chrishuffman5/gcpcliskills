# Sources — gcloud database-migration (Database Migration Service)

Official Google sources used to author this reference. (cloud.google.com URLs redirect to docs.cloud.google.com — both are official Google sources.)

## gcloud CLI reference
- https://cloud.google.com/sdk/gcloud/reference/database-migration — gcloud CLI reference for all database-migration command groups.

## Product documentation
- https://cloud.google.com/database-migration/docs — product docs home (all migration paths, concepts, and guides).
- https://cloud.google.com/database-migration/docs/overview — DMS overview: homogeneous vs. heterogeneous, CDC, connectivity, security.
- https://cloud.google.com/database-migration/docs/mysql/quickstart — quickstart: migrate MySQL to Cloud SQL for MySQL.
- https://cloud.google.com/database-migration/docs/mysql/configure-source-database — configure a MySQL source (binary logging, GTID, privileges, InnoDB).
- https://cloud.google.com/database-migration/docs/mysql/configure-connectivity — connectivity options (IP allowlist, reverse-SSH tunnel, VPC peering, Private Service Connect).

## API & IAM
- https://cloud.google.com/database-migration/docs/reference/rest — REST API reference; service ID `datamigration.googleapis.com`.
- https://cloud.google.com/iam/docs/roles-permissions/datamigration — IAM predefined roles for Database Migration Service.
