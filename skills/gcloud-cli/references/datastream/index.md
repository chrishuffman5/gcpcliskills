# gcloud datastream — command index

manage Cloud Datastream resources

- `gcloud datastream connection-profiles create` — create a Datastream connection profile
- `gcloud datastream connection-profiles delete` — delete a Datastream connection profile
- `gcloud datastream connection-profiles describe` — show details about a Datastream connection profile
- `gcloud datastream connection-profiles discover` — discover a Datastream connection profile
- `gcloud datastream connection-profiles list` — list Datastream connection profiles
- `gcloud datastream connection-profiles update` — update a Datastream connection profile
- `gcloud datastream locations describe` — show details about the location
- `gcloud datastream locations fetch-static-ips` — list Datastream static ips per location
- `gcloud datastream locations list` — list Datastream locations
- `gcloud datastream objects describe` — show details about a Stream object
- `gcloud datastream objects list` — list a Datastream stream objects
- `gcloud datastream objects lookup` — lookup a Datastream stream object
- `gcloud datastream objects start-backfill` — start a backfill job for a Stream object
- `gcloud datastream objects stop-backfill` — stop a backfill job for a Stream object
- `gcloud datastream operations cancel` — cancel a Datastream operation
- `gcloud datastream operations delete` — delete a Datastream operation
- `gcloud datastream operations describe` — show details about a operation
- `gcloud datastream operations list` — list operations
- `gcloud datastream private-connections create` — create a Datastream private connection
- `gcloud datastream private-connections delete` — delete a Datastream private connection
- `gcloud datastream private-connections describe` — show details about a Datastream private connection
- `gcloud datastream private-connections list` — list private connections
- `gcloud datastream routes create` — create a Datastream private connection route
- `gcloud datastream routes delete` — delete a Datastream private connection route
- `gcloud datastream routes describe` — show details about the route
- `gcloud datastream routes list` — list Datastream routes
- `gcloud datastream streams create` — create a Datastream stream
- `gcloud datastream streams delete` — delete a Datastream stream
- `gcloud datastream streams describe` — show details about a Datastream stream resource
- `gcloud datastream streams list` — list Datastream stream resources
- `gcloud datastream streams update` — updates a Datastream stream
