# gcloud notebooks — command index

notebooks Command Group

- `gcloud notebooks environments create` — request for creating environments
- `gcloud notebooks environments delete` — request for deleting environments
- `gcloud notebooks environments describe` — request for describing environments
- `gcloud notebooks environments list` — request for listing environments
- `gcloud notebooks instances add-iam-policy-binding` — add IAM policy binding for an instance
- `gcloud notebooks instances create` — request for creating an instance
- `gcloud notebooks instances delete` — request for deleting instances
- `gcloud notebooks instances describe` — request for describing instances
- `gcloud notebooks instances diagnose` — request for diagnose instances
- `gcloud notebooks instances get-health` — request for checking if a notebook instance is healthy
- `gcloud notebooks instances get-iam-policy` — get IAM policy for an instance
- `gcloud notebooks instances is-upgradeable` — request for checking if a notebook instance is upgradeable
- `gcloud notebooks instances list` — request for listing instances
- `gcloud notebooks instances migrate` — request for migrating instances
- `gcloud notebooks instances register` — request for registering instances
- `gcloud notebooks instances remove-iam-policy-binding` — remove IAM policy binding for an instance
- `gcloud notebooks instances reset` — request for resetting instances
- `gcloud notebooks instances rollback` — request for rolling back instances
- `gcloud notebooks instances set-iam-policy` — set the IAM policy for an Instance
- `gcloud notebooks instances start` — request for starting instances
- `gcloud notebooks instances stop` — request for stopping instances
- `gcloud notebooks instances update` — request for updating instances
- `gcloud notebooks instances upgrade` — request for upgrading instances
- `gcloud notebooks locations list` — request for listing locations
- `gcloud notebooks runtimes create` — request for creating an runtime
- `gcloud notebooks runtimes delete` — request for deleting runtimes
- `gcloud notebooks runtimes describe` — request for describing runtimes
- `gcloud notebooks runtimes diagnose` — request for diagnose runtimes
- `gcloud notebooks runtimes list` — request for listing runtimes
- `gcloud notebooks runtimes migrate` — request for migrating runtimes
- `gcloud notebooks runtimes reset` — request for resetting runtimes
- `gcloud notebooks runtimes start` — request for starting runtimes
- `gcloud notebooks runtimes stop` — request for stopping runtimes
- `gcloud notebooks runtimes switch` — request for switching runtimes
