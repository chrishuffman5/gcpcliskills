# gcloud edge-cache — command index

manage Media CDN resources

- `gcloud edge-cache keysets create` — create an EdgeCacheKeyset resource
- `gcloud edge-cache keysets delete` — delete an EdgeCacheKeyset resource
- `gcloud edge-cache keysets describe` — show details about an EdgeCacheKeyset resource
- `gcloud edge-cache keysets export` — export an EdgeCacheKeyset resource
- `gcloud edge-cache keysets import` — import an EdgeCacheKeyset resource
- `gcloud edge-cache keysets list` — list EdgeCacheKeyset resources
- `gcloud edge-cache keysets update` — update an EdgeCacheKeyset resource
- `gcloud edge-cache operations describe` — describe a long-running operation
- `gcloud edge-cache operations list` — list long-running operations
- `gcloud edge-cache origins create` — create an EdgeCacheOrigin resource
- `gcloud edge-cache origins delete` — delete an EdgeCacheOrigin resource
- `gcloud edge-cache origins describe` — show details about an EdgeCacheOrigin resource
- `gcloud edge-cache origins export` — export an EdgeCacheOrigin resource
- `gcloud edge-cache origins import` — import an EdgeCacheOrigin resource
- `gcloud edge-cache origins list` — list all EdgeCacheOrigin resources in a project
- `gcloud edge-cache origins update` — update an EdgeCacheOrigin resource
- `gcloud edge-cache services delete` — delete an EdgeCacheService resource
- `gcloud edge-cache services describe` — show details about an EdgeCacheService resource
- `gcloud edge-cache services export` — export an EdgeCacheService resource
- `gcloud edge-cache services import` — import an EdgeCacheService resource
- `gcloud edge-cache services invalidate-cache` — invalidate the cache for an EdgeCacheService resource
- `gcloud edge-cache services list` — list all EdgeCacheService resources in a project
- `gcloud edge-cache services update` — update an EdgeCacheService resource
