# gcloud developer-connect — command index

manage Developer Connect resources

- `gcloud developer-connect connections create` — create a connection resource
- `gcloud developer-connect connections delete` — delete a single connection
- `gcloud developer-connect connections describe` — get details of a single connection resource
- `gcloud developer-connect connections list` — list connections
- `gcloud developer-connect connections update` — update the parameters of a single connection
- `gcloud developer-connect connections git-repository-links create` — create a git repository link
- `gcloud developer-connect connections git-repository-links delete` — delete a single git repository link
- `gcloud developer-connect connections git-repository-links describe` — get details of a single git repository link
- `gcloud developer-connect connections git-repository-links fetch-read-token` — fetch the read token of a given gitRepositoryLink
- `gcloud developer-connect connections git-repository-links fetch-read-write-token` — fetch the read/write token of a given gitRepositoryLink
- `gcloud developer-connect connections git-repository-links list` — list all git repository links in a connection
- `gcloud developer-connect insights-configs create` — create an insight config
- `gcloud developer-connect insights-configs delete` — delete insightsConfigs
- `gcloud developer-connect insights-configs describe` — describe insightsConfigs
- `gcloud developer-connect insights-configs list` — list insightsConfigs
- `gcloud developer-connect insights-configs update` — update the configuration of an insight config
- `gcloud developer-connect operations cancel` — cancel operations
- `gcloud developer-connect operations delete` — delete operations
- `gcloud developer-connect operations describe` — describe operations
- `gcloud developer-connect operations list` — list operations
- `gcloud developer-connect operations wait` — wait operations
