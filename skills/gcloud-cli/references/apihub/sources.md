# gcloud apihub — sources

Official source URLs backing this reference. `gcloud apihub` is a GA command group (it appeared after Google Cloud SDK 552.0.0; verified against the online reference as of SDK 575.0.0).

## gcloud CLI reference

- https://cloud.google.com/sdk/gcloud/reference/apihub — `gcloud apihub` command group (GA surface, subgroup enumeration)
- https://docs.cloud.google.com/sdk/gcloud/reference/apihub/addons — `addons` group (describe, list, manage-config)
- https://docs.cloud.google.com/sdk/gcloud/reference/apihub/api-hub-instances — `api-hub-instances` group (create, delete, describe, lookup)
- https://docs.cloud.google.com/sdk/gcloud/reference/apihub/apis — `apis` group (create, delete, describe, list, update)
- https://docs.cloud.google.com/sdk/gcloud/reference/apihub/apis/versions — `apis versions` group (create, delete, describe, list, update)
- https://docs.cloud.google.com/sdk/gcloud/reference/apihub/apis/versions/operations — `apis versions operations` group (create, delete, describe, list, update)
- https://docs.cloud.google.com/sdk/gcloud/reference/apihub/apis/versions/specs — `apis versions specs` group (create, delete, describe, get-contents, lint, list, update)
- https://docs.cloud.google.com/sdk/gcloud/reference/apihub/attributes — `attributes` group (create, delete, describe, list, update)
- https://docs.cloud.google.com/sdk/gcloud/reference/apihub/curations — `curations` group (create, delete, describe, list, update)
- https://docs.cloud.google.com/sdk/gcloud/reference/apihub/dependencies — `dependencies` group (create, delete, describe, list, update)
- https://docs.cloud.google.com/sdk/gcloud/reference/apihub/deployments — `deployments` group (create, delete, describe, list, update)

Individual command pages under each group URL above (`.../<group>/<command>`) were used for synopses, flags, and examples.
