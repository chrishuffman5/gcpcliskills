# gcloud data-catalog — sources

Official source URLs for the Data Catalog service reference. Data Catalog is deprecated and scheduled for discontinuation on June 1, 2026; its successor is Knowledge Catalog (Dataplex Universal Catalog).

## gcloud CLI reference

- https://cloud.google.com/sdk/gcloud/reference/data-catalog — gcloud data-catalog CLI reference (GA)
- https://cloud.google.com/sdk/gcloud/reference/beta/data-catalog — gcloud beta data-catalog CLI reference

## Product documentation

- https://cloud.google.com/data-catalog/docs — Data Catalog product docs home
- https://cloud.google.com/data-catalog/docs/concepts/overview — core concepts (entries, entry groups, tags, tag templates, taxonomies, policy tags)
- https://cloud.google.com/data-catalog/docs/concepts/iam — IAM roles and permissions
- https://cloud.google.com/data-catalog/docs/how-to/search — searching data assets (scope, filters, syntax)
- https://cloud.google.com/data-catalog/docs/how-to/search-reference — search query syntax reference
- https://cloud.google.com/data-catalog/docs/reference/rest — REST API reference (endpoint `datacatalog.googleapis.com`)
