# gcloud memorystore — command index

manage Memorystore resources

- `gcloud memorystore backup-collections describe` — describe backupCollections
- `gcloud memorystore backup-collections list` — list backupCollections
- `gcloud memorystore backup-collections backups delete` — delete backups
- `gcloud memorystore backup-collections backups describe` — describe backups
- `gcloud memorystore backup-collections backups export` — export backups
- `gcloud memorystore backup-collections backups list` — list backups
- `gcloud memorystore instances backup` — backup instances
- `gcloud memorystore instances create` — create a Memorystore instance
- `gcloud memorystore instances delete` — delete a Memorystore instance
- `gcloud memorystore instances describe` — get details of a Memorystore instance
- `gcloud memorystore instances get-certificate-authority` — get certificate authority details of a Memorystore instance
- `gcloud memorystore instances list` — list all Memorystore instances in a specified project and location
- `gcloud memorystore instances reschedule-maintenance` — reschedule maintenance window for an instance
- `gcloud memorystore instances update` — update the configuration of a Memorystore instance
- `gcloud memorystore locations describe` — show metadata for a Memorystore for Valkey location
- `gcloud memorystore locations list` — list Memorystore for Valkey locations
- `gcloud memorystore operations cancel` — cancel a Memorystore operation
- `gcloud memorystore operations delete` — delete a Memorystore operation
- `gcloud memorystore operations describe` — describe a Memorystore operation
- `gcloud memorystore operations list` — list Memorystore operations
