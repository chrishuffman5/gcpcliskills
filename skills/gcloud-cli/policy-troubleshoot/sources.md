# gcloud policy-troubleshoot — sources

## gcloud CLI reference
- https://cloud.google.com/sdk/gcloud/reference/policy-troubleshoot — `gcloud policy-troubleshoot` command group (GA)
- https://cloud.google.com/sdk/gcloud/reference/policy-troubleshoot/iam — `gcloud policy-troubleshoot iam` subcommand: all flags and examples
- https://cloud.google.com/sdk/gcloud/reference/beta/policy-troubleshoot — `gcloud beta policy-troubleshoot`
- https://cloud.google.com/sdk/gcloud/reference/alpha/policy-troubleshoot — `gcloud alpha policy-troubleshoot`
