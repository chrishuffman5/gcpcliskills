# gcloud recaptcha — command index

manage reCAPTCHA Enterprise Keys

- `gcloud recaptcha firewall-policies create` — create a Firewall Policy
- `gcloud recaptcha firewall-policies delete` — delete one or more reCAPTCHA Firewall Policies
- `gcloud recaptcha firewall-policies describe` — describe reCAPTCHA Firewall Policy
- `gcloud recaptcha firewall-policies list` — list reCAPTCHA Firewall Policies
- `gcloud recaptcha firewall-policies reorder` — reorder all Firewall Policies
- `gcloud recaptcha firewall-policies update` — update a Firewall Policy
- `gcloud recaptcha keys add-ip-override` — add an IP override to a key
- `gcloud recaptcha keys create` — create a Key
- `gcloud recaptcha keys delete` — delete one or more reCAPTCHA Keys
- `gcloud recaptcha keys describe` — describe reCAPTCHA Key
- `gcloud recaptcha keys list` — list reCAPTCHA Keys
- `gcloud recaptcha keys list-ip-overrides` — list IP overrides for a key
- `gcloud recaptcha keys migrate` — migrate a key to reCAPTCHA Enterprise
- `gcloud recaptcha keys remove-ip-override` — remove an IP override from a key
- `gcloud recaptcha keys update` — update a Key
