# gcloud certificate-manager — command index

manage SSL certificates for your Google Cloud projects

- `gcloud certificate-manager certificates create` — create a certificate
- `gcloud certificate-manager certificates delete` — delete a certificate
- `gcloud certificate-manager certificates describe` — describe an existing certificate
- `gcloud certificate-manager certificates list` — list certificates
- `gcloud certificate-manager certificates update` — update a certificate
- `gcloud certificate-manager dns-authorizations create` — create a DNS Authorization
- `gcloud certificate-manager dns-authorizations delete` — delete a DNS Authorization
- `gcloud certificate-manager dns-authorizations describe` — show details about a DNS Authorization
- `gcloud certificate-manager dns-authorizations list` — list all DNS Authorizations in a project
- `gcloud certificate-manager dns-authorizations update` — update a DNS Authorization
- `gcloud certificate-manager issuance-configs create` — create a Certificate Issuance Config
- `gcloud certificate-manager issuance-configs delete` — delete a Certificate Issuance Config
- `gcloud certificate-manager issuance-configs describe` — show details about a Certificate Issuance Config
- `gcloud certificate-manager issuance-configs list` — list all Certificate Issuance Configs in a project
- `gcloud certificate-manager issuance-configs update` — update a Certificate Issuance Config
- `gcloud certificate-manager maps create` — create a certificate map
- `gcloud certificate-manager maps delete` — delete a certificate map
- `gcloud certificate-manager maps describe` — describe an existing certificate map
- `gcloud certificate-manager maps list` — list certificate maps
- `gcloud certificate-manager maps update` — update a certificate map
- `gcloud certificate-manager maps entries create` — create a certificate map entry
- `gcloud certificate-manager maps entries delete` — delete a certificate map entry
- `gcloud certificate-manager maps entries describe` — describe an existing certificate map entry
- `gcloud certificate-manager maps entries list` — list certificate map entries
- `gcloud certificate-manager maps entries update` — update a certificate map entry
- `gcloud certificate-manager operations describe` — describe a long-running operation
- `gcloud certificate-manager operations list` — list long-running operations
- `gcloud certificate-manager trust-configs create` — create TrustConfig
- `gcloud certificate-manager trust-configs delete` — delete TrustConfig
- `gcloud certificate-manager trust-configs describe` — show details about a TrustConfig
- `gcloud certificate-manager trust-configs export` — export TrustConfig
- `gcloud certificate-manager trust-configs import` — import TrustConfig
- `gcloud certificate-manager trust-configs list` — list all TrustConfigs in a project
- `gcloud certificate-manager trust-configs update` — update TrustConfig
