# gcloud redis — command index

manage Cloud Memorystore Redis resources

- `gcloud redis clusters add-cluster-endpoints` — add more cluster endpoints
- `gcloud redis clusters create` — create a new Memorystore for Redis Cluster instance
- `gcloud redis clusters create-backup` — create a backup of a Redis cluster
- `gcloud redis clusters delete` — delete a Memorystore for Redis Cluster instance
- `gcloud redis clusters describe` — show metadata for a Memorystore for Redis Cluster instance
- `gcloud redis clusters detach` — detach a secondary cluster
- `gcloud redis clusters detach-secondaries` — detach one or more secondary clusters from the primary cluster
- `gcloud redis clusters get-cluster-certificate-authority` — get the certificate authority information for a Memorystore for Redis Cluster instance
- `gcloud redis clusters list` — list Memorystore for Redis Cluster instances
- `gcloud redis clusters remove-cluster-endpoints` — remove existing Memorystore cluster endpoints
- `gcloud redis clusters reschedule-maintenance` — reschedule maintenance window for a Memorystore for Redis Cluster instance
- `gcloud redis clusters switchover` — switchover to a secondary cluster
- `gcloud redis clusters update` — update Memorystore Cluster for Redis instance
- `gcloud redis clusters backup-collections describe` — show metadata for a backup collection
- `gcloud redis clusters backup-collections list` — list backup collections in a region
- `gcloud redis clusters backups delete` — delete a Memorystore for Redis Cluster backup
- `gcloud redis clusters backups describe` — show metadata for a Memorystore for Redis Cluster backup
- `gcloud redis clusters backups export` — export a Redis cluster backup to a Google Cloud Storage bucket
- `gcloud redis clusters backups list` — list backups under a backup collection in a region
- `gcloud redis instances create` — create a Memorystore Redis instance
- `gcloud redis instances delete` — delete a Redis instance
- `gcloud redis instances describe` — show metadata for a Memorystore Redis instance
- `gcloud redis instances export` — export data from a Memorystore Redis instance to Google Cloud Storage
- `gcloud redis instances failover` — failover a standard tier Cloud Memorystore for Redis instance from the master node to its replica
- `gcloud redis instances get-auth-string` — show AUTH string for a Memorystore Redis instance
- `gcloud redis instances import` — import data to a Memorystore Redis instance from Google Cloud Storage
- `gcloud redis instances list` — list Memorystore Redis instances
- `gcloud redis instances reschedule-maintenance` — reschedule maintenance window for a Redis instance
- `gcloud redis instances update` — update Memorystore Redis instances
- `gcloud redis instances upgrade` — upgrade a Memorystore for Redis instance to a specified Redis version
- `gcloud redis operations cancel` — cancel a Memorystore Redis import or export operation
- `gcloud redis operations describe` — show metadata for a Memorystore Redis operation
- `gcloud redis operations list` — list Memorystore Redis operations
- `gcloud redis regions describe` — show metadata for a Memorystore Redis region
- `gcloud redis regions list` — list Memorystore Redis regions
- `gcloud redis zones list` — list Memorystore Redis zones
