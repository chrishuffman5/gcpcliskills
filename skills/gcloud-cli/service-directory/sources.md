# Sources — gcloud service-directory (Service Directory)

Official source URLs backing this reference. Verified during research.

- https://cloud.google.com/service-directory/docs — Product docs home (navigation hub for all Service Directory guides).
- https://cloud.google.com/service-directory/docs/overview — Concept overview: what Service Directory is, the namespace/service/endpoint model.
- https://cloud.google.com/service-directory/docs/configuring-service-directory — How-to guide with gcloud command sequences for creating and managing resources.
- https://cloud.google.com/service-directory/docs/access-control — IAM roles reference: predefined roles and their permissions.
- https://cloud.google.com/service-directory/docs/reference/rest — REST API reference (`servicedirectory.googleapis.com` v1 and v1beta1).
- https://cloud.google.com/sdk/gcloud/reference/service-directory — gcloud CLI reference (GA): all command groups.
- https://cloud.google.com/sdk/gcloud/reference/beta/service-directory — gcloud beta CLI reference: confirms beta/alpha variants.
