# gcloud compliance-manager — command index

manage Compliance Manager resources

- `gcloud compliance-manager cloud-control-deployments describe` — get a cloud control deployment
- `gcloud compliance-manager cloud-control-deployments list` — list Cloud Control Deployments
- `gcloud compliance-manager cloud-controls create` — create a cloud control
- `gcloud compliance-manager cloud-controls delete` — delete a cloud control
- `gcloud compliance-manager cloud-controls describe` — get a cloud control
- `gcloud compliance-manager cloud-controls list` — list cloud controls
- `gcloud compliance-manager framework-deployments create` — create a framework deployment
- `gcloud compliance-manager framework-deployments delete` — delete a framework deployment
- `gcloud compliance-manager framework-deployments describe` — get a framework deployment
- `gcloud compliance-manager framework-deployments list` — list framework deployments
- `gcloud compliance-manager frameworks create` — create a framework
- `gcloud compliance-manager frameworks delete` — delete a framework
- `gcloud compliance-manager frameworks describe` — get a framework
- `gcloud compliance-manager frameworks list` — list frameworks
- `gcloud compliance-manager operations cancel` — cancel operations
- `gcloud compliance-manager operations delete` — delete operations
- `gcloud compliance-manager operations describe` — describe operations
- `gcloud compliance-manager operations list` — list operations
- `gcloud compliance-manager operations wait` — wait operations
