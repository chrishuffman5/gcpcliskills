# gcloud recommender — command index

manage Cloud recommendations and recommendation rules

- `gcloud recommender insight-type-config describe` — describe an insight type configuration
- `gcloud recommender insight-type-config update` — update an insight type configuration
- `gcloud recommender insights describe` — describe an insight
- `gcloud recommender insights list` — list insights for a Google Cloud entity
- `gcloud recommender insights mark-accepted` — mark an insight's state as ACCEPTED
- `gcloud recommender recommendations describe` — describe a recommendation for a Cloud project
- `gcloud recommender recommendations list` — list operations for a recommendation
- `gcloud recommender recommendations mark-claimed` — mark a recommendation's state as CLAIMED
- `gcloud recommender recommendations mark-dismissed` — mark recommendation's state as DISMISSED
- `gcloud recommender recommendations mark-failed` — mark a recommendation's state as FAILED
- `gcloud recommender recommendations mark-succeeded` — mark a recommendation's state as SUCCEEDED
- `gcloud recommender recommender-config describe` — describe a recommender configuration
- `gcloud recommender recommender-config update` — update a recommender configuration
