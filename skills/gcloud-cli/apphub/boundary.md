# gcloud apphub boundary

manage App Hub boundaries

### `gcloud apphub boundary describe`

Show metadata for an App Hub boundary

Show metadata for an App Hub boundary.

**Synopsis:**
```
gcloud apphub boundary describe [--location=LOCATION]
    [GCLOUD_WIDE_FLAG ...]
```

**Optional flags:**

| Flag | Value | Default | Description |
|------|-------|---------|-------------|
| `--location` | LOCATION |  | _[* set the property core/project.]_ ID of the location or fully qualified identifier for the location. To set the location attribute: + provide the argument --location on the command line; + Boundaries only support global location. |


[Official reference](https://cloud.google.com/sdk/gcloud/reference/apphub/boundary/describe)

---
### `gcloud apphub boundary update`

Update an App Hub boundary

Update an App Hub boundary.

**Synopsis:**
```
gcloud apphub boundary update [--async] [--crm-node=CRM_NODE]
    [--location=LOCATION] [--request-id=REQUEST_ID] [GCLOUD_WIDE_FLAG ...]
```

**Optional flags:**

| Flag | Value | Default | Description |
|------|-------|---------|-------------|
| `--async` |  |  | Return immediately, without waiting for the operation in progress to complete. |
| `--request-id` | REQUEST_ID |  | _[+ Boundaries only support global location.]_ An optional request ID to identify requests. |


[Official reference](https://cloud.google.com/sdk/gcloud/reference/apphub/boundary/update)
