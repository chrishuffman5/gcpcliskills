# gcloud filestore — command index

create and manipulate Filestore resources

- `gcloud filestore backups create` — create a Filestore backup
- `gcloud filestore backups delete` — delete a Filestore backup
- `gcloud filestore backups describe` — describe a Filestore backup
- `gcloud filestore backups list` — list Filestore backups
- `gcloud filestore backups update` — update a Filestore backup
- `gcloud filestore instances create` — create a Filestore instance
- `gcloud filestore instances delete` — delete a Filestore instance
- `gcloud filestore instances describe` — show metadata for a Filestore instance
- `gcloud filestore instances list` — list Filestore instances
- `gcloud filestore instances pause-replica` — pause a Filestore replica instance
- `gcloud filestore instances promote-replica` — promote a Filestore standby replication instance
- `gcloud filestore instances restore` — restore a Filestore instance from a backup
- `gcloud filestore instances resume-replica` — resume a Filestore replica instance
- `gcloud filestore instances revert` — revert a Filestore instance
- `gcloud filestore instances update` — update a Filestore instance
- `gcloud filestore instances snapshots create` — create a Filestore snapshot
- `gcloud filestore instances snapshots delete` — delete a Filestore snapshot
- `gcloud filestore instances snapshots describe` — display information about a Filestore snapshot
- `gcloud filestore instances snapshots list` — list Filestore snapshots
- `gcloud filestore instances snapshots update` — update the description or labels of a Filestore snapshot
- `gcloud filestore locations describe` — describe a Filestore location
- `gcloud filestore locations list` — list all Filestore locations
- `gcloud filestore operations cancel` — cancel a Filestore operation
- `gcloud filestore operations describe` — describe a Filestore operation
- `gcloud filestore operations list` — list all Filestore operations
- `gcloud filestore regions list` — list all Filestore regions
- `gcloud filestore zones list` — list all Filestore zones
