# gcloud billing — command index

manage billing accounts and associate them with projects

- `gcloud billing accounts add-iam-policy-binding` — add an IAM policy binding to a Cloud Billing account
- `gcloud billing accounts describe` — show metadata for a billing account
- `gcloud billing accounts get-iam-policy` — get the IAM policy for a Cloud Billing account
- `gcloud billing accounts list` — list all active billing accounts
- `gcloud billing accounts remove-iam-policy-binding` — remove an IAM policy binding from a Cloud Billing account
- `gcloud billing accounts set-iam-policy` — set the IAM policy for a Cloud Billing account
- `gcloud billing budgets create` — create a budget
- `gcloud billing budgets delete` — delete a budget
- `gcloud billing budgets describe` — describe a budget
- `gcloud billing budgets list` — list budgets
- `gcloud billing budgets update` — update a budget
- `gcloud billing projects describe` — show detailed billing information for a project
- `gcloud billing projects link` — link a project with a billing account
- `gcloud billing projects list` — list all active projects associated with the specified billing account
- `gcloud billing projects unlink` — unlink the account (if any) linked with a project
