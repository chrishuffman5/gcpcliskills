# gcloud identity — command index

manage Cloud Identity Groups and Memberships resources

- `gcloud identity groups create` — create a new group
- `gcloud identity groups delete` — delete an existing group
- `gcloud identity groups describe` — describe an existing group
- `gcloud identity groups search` — searches for Groups matching a specified query
- `gcloud identity groups update` — update a group
- `gcloud identity groups memberships add` — create a new membership in an existing group
- `gcloud identity groups memberships check-transitive-membership` — check a potential member for transitive membership in a group
- `gcloud identity groups memberships delete` — delete a membership from an existing group
- `gcloud identity groups memberships describe` — describe a membership in a group
- `gcloud identity groups memberships get-membership-graph` — get a membership graph of just a member or both a member and a group
- `gcloud identity groups memberships list` — list memberships in an existing group
- `gcloud identity groups memberships modify-membership-roles` — add/remove/modify membership roles of a membership in a group
- `gcloud identity groups memberships search-transitive-groups` — search transitive groups of a member
- `gcloud identity groups memberships search-transitive-memberships` — search transitive memberships of a group
