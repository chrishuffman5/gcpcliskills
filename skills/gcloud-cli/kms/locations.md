# gcloud kms locations

view locations available for a project

### `gcloud kms locations list`

List the project's locations

Lists all locations available for this project.

**Synopsis:**
```
gcloud kms locations list [--filter=EXPRESSION] [--limit=LIMIT]
    [--page-size=PAGE_SIZE] [--sort-by=[FIELD,...]] [--uri]
    [GCLOUD_WIDE_FLAG ...]
```

[Official reference](https://cloud.google.com/sdk/gcloud/reference/kms/locations/list)
