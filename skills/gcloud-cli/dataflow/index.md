# gcloud dataflow — command index

manage Google Cloud Dataflow resources

- `gcloud dataflow flex-template build` — builds a flex template file from the specified parameters
- `gcloud dataflow flex-template run` — runs a job from the specified path
- `gcloud dataflow jobs archive` — archives a job
- `gcloud dataflow jobs cancel` — cancels all jobs that match the command line arguments
- `gcloud dataflow jobs describe` — outputs the Job object resulting from the Get API
- `gcloud dataflow jobs drain` — drains all jobs that match the command line arguments
- `gcloud dataflow jobs list` — lists all jobs in a particular project, optionally filtered by region
- `gcloud dataflow jobs run` — runs a job from the specified path
- `gcloud dataflow jobs show` — shows a short description of the given job
- `gcloud dataflow jobs update-options` — update pipeline options on-the-fly for running Dataflow jobs
- `gcloud dataflow snapshots create` — creates a snapshot for a Cloud Dataflow job
- `gcloud dataflow snapshots delete` — delete a Cloud Dataflow snapshot
- `gcloud dataflow snapshots describe` — describe a Cloud Dataflow snapshot
- `gcloud dataflow snapshots list` — list all Cloud Dataflow snapshots in a project in the specified region, optionally filtered by job ID
- `gcloud dataflow yaml run` — runs a job from the specified path
