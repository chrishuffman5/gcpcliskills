# gcloud telco-automation — command index

manage Telco Automation resources

- `gcloud telco-automation operations describe` — get description of a long-running telco automation operation
- `gcloud telco-automation operations wait` — poll long-running telco automation operation until it completes
- `gcloud telco-automation orchestration-cluster create` — create a telco automation orchestration cluster
- `gcloud telco-automation orchestration-cluster delete` — delete a telco automation orchestration cluster
- `gcloud telco-automation orchestration-cluster describe` — show details about the orchestration cluster
- `gcloud telco-automation orchestration-cluster list` — list telco automation orchestration clusters
