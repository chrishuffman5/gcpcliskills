# gcloud batch — sources

Official source URLs for the `gcloud batch` (Batch) reference.

## Product documentation
- https://cloud.google.com/batch/docs — Batch documentation home (product overview, quickstarts, how-to guides)
- https://cloud.google.com/batch/docs/get-started — Get started: APIs to enable, IAM roles, prerequisites
- https://cloud.google.com/batch/docs/jobs-overview — Job creation and execution overview (jobs, task groups, runnables)
- https://cloud.google.com/batch/docs/create-run-job-basic-script — Create and run a basic script job with gcloud
- https://cloud.google.com/batch/docs/manage-job — Manage a job (list, describe, cancel, delete)
