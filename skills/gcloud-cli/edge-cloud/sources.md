# Sources — gcloud edge-cloud (Google Distributed Cloud Edge)

Official sources backing the `edge-cloud` reference. Cited by the router SKILL.md.

## gcloud CLI reference

- https://cloud.google.com/sdk/gcloud/reference/edge-cloud — `gcloud edge-cloud` command reference (GA: `container`, `networking` subgroups)
- https://cloud.google.com/sdk/gcloud/reference/edge-cloud/container/clusters/create — `clusters create` flags, defaults, and examples
- https://cloud.google.com/sdk/gcloud/reference/alpha/edge-cloud — `gcloud alpha edge-cloud` surface (alpha-only subgroups)

## Product documentation

- https://docs.cloud.google.com/distributed-cloud/edge/latest/docs — Google Distributed Cloud Edge docs home (overview, clusters, networking, hardware management)
- https://docs.cloud.google.com/distributed-cloud/edge/latest/docs/permissions — IAM roles for Edge Container, Edge Network, and GDC Hardware Management APIs; confirms API service names (`edgecontainer.googleapis.com`, `edgenetwork.googleapis.com`, `gdchardwaremanagement.googleapis.com`)
