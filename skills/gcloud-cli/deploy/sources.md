# gcloud deploy — sources

Citation record for the `gcloud deploy` (Google Cloud Deploy) reference. All URLs were verified loading during research.

## gcloud CLI reference

- https://cloud.google.com/sdk/gcloud/reference/deploy — gcloud CLI reference root for the deploy group
- https://cloud.google.com/sdk/gcloud/reference/beta/deploy — beta command surface (mirrors GA)

## Product documentation

- https://cloud.google.com/deploy/docs/overview — product overview: concepts, resource model, supported runtimes (product docs home)
- https://cloud.google.com/deploy/docs/create-pipeline-targets — create delivery pipelines and targets with `gcloud deploy apply`
- https://cloud.google.com/deploy/docs/deploying-application — create releases and trigger rollouts
- https://cloud.google.com/deploy/docs/view-pipeline — list and describe pipelines, targets, releases, rollouts
- https://cloud.google.com/deploy/docs/config-files — YAML schema reference for DeliveryPipeline, Target, Automation, DeployPolicy
- https://cloud.google.com/deploy/docs/iam-roles-permissions — predefined IAM roles and permissions for Cloud Deploy
