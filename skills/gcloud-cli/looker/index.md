# gcloud looker — command index

manage Looker resources

- `gcloud looker backups create` — create a backup of a Looker instance
- `gcloud looker backups delete` — delete a backup of a Looker instance
- `gcloud looker backups describe` — show metadata of a backup for a Looker instance
- `gcloud looker backups list` — list backups of a Looker instance
- `gcloud looker instances create` — create a Looker instance
- `gcloud looker instances delete` — delete a Looker instance
- `gcloud looker instances describe` — show metadata for a Looker instance
- `gcloud looker instances export` — export a Looker instance
- `gcloud looker instances import` — import a Looker instance
- `gcloud looker instances list` — list Looker instances
- `gcloud looker instances restart` — restart a Looker instance
- `gcloud looker instances restore` — restore a Looker instance from a backup
- `gcloud looker instances update` — update a Looker instance
- `gcloud looker operations cancel` — cancel a Looker import or export operation
- `gcloud looker operations describe` — show metadata for a Looker operation
- `gcloud looker operations list` — list Looker operations
- `gcloud looker regions list` — list Looker regions
