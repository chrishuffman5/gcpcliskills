# gcloud agent-registry — command index

manage Agent Registry resources

- `gcloud agent-registry agents describe` — get details of an agent
- `gcloud agent-registry agents list` — list accessible agents
- `gcloud agent-registry agents search` — search for agents matching a query
- `gcloud agent-registry bindings create` — create a new binding
- `gcloud agent-registry bindings delete` — delete a binding connection
- `gcloud agent-registry bindings describe` — retrieve binding details
- `gcloud agent-registry bindings fetch-available` — fetch bindings
- `gcloud agent-registry bindings list` — list bindings
- `gcloud agent-registry bindings update` — modify binding parameters
- `gcloud agent-registry endpoints describe` — retrieve endpoint details
- `gcloud agent-registry endpoints list` — enumerate service endpoints
- `gcloud agent-registry mcp-servers describe` — get details of an MCP server
- `gcloud agent-registry mcp-servers list` — list registered MCP servers
- `gcloud agent-registry mcp-servers search` — search MCP servers matching criteria
- `gcloud agent-registry operations cancel` — cancel operations
- `gcloud agent-registry operations delete` — delete operations
- `gcloud agent-registry operations describe` — describe operations
- `gcloud agent-registry operations list` — list operations
- `gcloud agent-registry operations wait` — wait operations
- `gcloud agent-registry services create` — register a new service
- `gcloud agent-registry services delete` — remove a registered service
- `gcloud agent-registry services describe` — get details of a registered service
- `gcloud agent-registry services list` — list registered services
- `gcloud agent-registry services update` — modify service parameters
