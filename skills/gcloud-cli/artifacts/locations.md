# gcloud artifacts locations

manage Artifact Registry resource locations

### `gcloud artifacts locations list`

List all Artifact Registry supported locations

List all Artifact Registry supported locations.

**Synopsis:**
```
gcloud artifacts locations list [--filter=EXPRESSION] [--limit=LIMIT]
    [--page-size=PAGE_SIZE] [--sort-by=[FIELD,...]] [GCLOUD_WIDE_FLAG ...]
```

**Examples:**
```bash
To list all supported locations:

    $ gcloud artifacts locations list
```

[Official reference](https://cloud.google.com/sdk/gcloud/reference/artifacts/locations/list)
