# gcloud lustre — command index

manage Lustre resources

- `gcloud lustre instances create` — creates a Managed Lustre instance
- `gcloud lustre instances delete` — deletes a Managed Lustre instance
- `gcloud lustre instances describe` — gets details of a single Managed Lustre instance
- `gcloud lustre instances export-data` — exports data from Managed Lustre instance to Cloud Storage
- `gcloud lustre instances import-data` — imports data from Cloud Storage to Managed Lustre instance
- `gcloud lustre instances list` — list Lustre instances
- `gcloud lustre instances update` — updates the parameters of a single Managed Lustre instance
- `gcloud lustre operations cancel` — cancel operations
- `gcloud lustre operations delete` — delete operations
- `gcloud lustre operations describe` — describe operations
- `gcloud lustre operations list` — list operations
- `gcloud lustre operations wait` — wait operations
