# gcloud biglake — command index

create and manage Google Cloud BigLake resources

- `gcloud biglake iceberg catalogs create` — create a BigLake Iceberg REST catalog
- `gcloud biglake iceberg catalogs delete` — delete a BigLake Iceberg REST catalog
- `gcloud biglake iceberg catalogs describe` — describe a BigLake Iceberg REST catalog
- `gcloud biglake iceberg catalogs failover` — failover a BigLake Iceberg REST catalog
- `gcloud biglake iceberg catalogs get-iam-policy` — get the IAM policy for a BigLake Iceberg REST catalog
- `gcloud biglake iceberg catalogs list` — list BigLake Iceberg REST catalogs
- `gcloud biglake iceberg catalogs set-iam-policy` — set the IAM policy for a BigLake Iceberg REST catalog
- `gcloud biglake iceberg catalogs update` — update a BigLake Iceberg REST catalog
- `gcloud biglake iceberg namespaces create` — create a BigLake Iceberg REST namespace
- `gcloud biglake iceberg namespaces delete` — delete a BigLake Iceberg REST namespace
- `gcloud biglake iceberg namespaces describe` — describe a BigLake Iceberg REST namespace
- `gcloud biglake iceberg namespaces get-iam-policy` — get the IAM policy for a BigLake Iceberg REST catalog namespace
- `gcloud biglake iceberg namespaces list` — list BigLake Iceberg REST namespaces
- `gcloud biglake iceberg namespaces set-iam-policy` — set the IAM policy for a BigLake Iceberg REST catalog namespace
- `gcloud biglake iceberg namespaces update` — update a BigLake Iceberg REST namespace
- `gcloud biglake iceberg tables create` — create a BigLake Iceberg table
- `gcloud biglake iceberg tables delete` — delete a BigLake Iceberg table
- `gcloud biglake iceberg tables describe` — describe a BigLake Iceberg table
- `gcloud biglake iceberg tables get-iam-policy` — get the IAM policy for a BigLake Iceberg REST catalog table
- `gcloud biglake iceberg tables list` — list BigLake Iceberg REST tables
- `gcloud biglake iceberg tables register` — register a BigLake Iceberg table
- `gcloud biglake iceberg tables set-iam-policy` — set the IAM policy for a BigLake Iceberg REST catalog table
- `gcloud biglake iceberg tables update` — update a BigLake Iceberg table
